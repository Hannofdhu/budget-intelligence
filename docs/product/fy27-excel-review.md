# FY27 Excel 定版回看

## 入口与边界

- 本机入口：`/budget/workspace?archive=fy27&step=5`，年度选择中提供 FY27。
- 五步导航沿用年度预算布局：目标与范围、入口人数、招生参数、资源与财务、预算概览。
- 本视图使用原 Excel 保存值，只读，不调用预算写入、计算、确认或发布命令，不替代 FY28 当前版本。
- “已定版”是用户确认的历史事实，不伪造系统发布时间、审批人、修订编号或门禁通过状态。2026-10-02 起，前台不再要求使用者了解历史工作簿。
- 输入源为项目根目录的 FY27 Excel，以及 `output/fy27-shadow/source-cells.json`。两者 SHA-256 必须一致。文件变化或提取缺失时停止读取，不显示陈旧数据。
- 原 Excel 与提取数据受 Git 忽略规则保护；不在前端静态资源或源代码中内嵌业务数据。

## 映射

- 滚动表 A/B/C/D/E/F/G：赛道、产品、是否入口、年级、来源年级、科目、校区。
- W：全年确认收入；AE：年级错位后的春续暑基数；AG：期初不含税结转；AH：最低班均。
- 四季按原列组映射。汇总收入使用 AX、BO、CF、CW 的保存值，并与 W 全年列以分为精度独立核对。
- 续班率、新生占比、价格、折扣、结转节奏按原辅助键关联参数表，保持 Excel 首个精确匹配语义。空值、文本“-”和数值零分别保留。
- 页面比例不平均各行比率。综合折扣使用业务收入合计 / 原价收入合计；明细参数直接读取原值。
- 全年人数是季度人次之和，不表示去重学员人数。
- 原通知目标仅用于历史对照，不能作为 FY27 重新调平要求。
- 零值行不删除；最低班均补新生公式、负数结转保留为历史依据，不放宽系统新预算的校验。

## 本机访问

历史接口沿用本机试用启用限制、身份及部门权限，另外检查由 Vite 代理从连接地址覆盖写入的客户端地址。局域网真实地址、缺少该标记的请求均拒绝。现有 FY28 合成试用仍可按原方式共享。

如以后希望同事查看真实 FY27，需另行明确授权范围和部署方式，不自动扩大共享。

## 已验证

- 238 个业务单元，952 条季度明细，全年收入与原 Excel 对齐到分。
- 入口总人次、七年级入口、春续暑基数、暑假老生分别核对，避免混淆范围。
- 逐行映射值与保存值一致，原表公式和参数位置可追溯。
- 修改源文件哈希、修改全年合计、跨部门读取、局域网读取均有回归测试。
- 早期 UI 实测五步切换、组合筛选、明细依据及局域网拒绝访问；该记录仅说明当时状态。概览沿用汇总与明细同页联动；最新用户要求已取消前台依据入口，见下节。

## 最新界面与导出（2026-10-02）

- 移除“查看依据”“来源与口径”“参数来源”，不显示历史文件、单元格或参数位置；内部源值及校验不删除。
- 五个步骤的明细导出改为 XLSX，金额、人次、比例使用数值单元格。维度保留文本，空白、文本“-”、零和负数不混淆；显示格式不改变底层保存精度。
- 结转字段改名为“当季业务确认收入（不含税，元）”“递延至下季收入（不含税，元）”。二者合计 112,480,004.34 元，加期初 7,847,731.60 元、扣 FY28 递延 7,323,117.35 元，得到全年确认收入 113,004,618.59 元。
- 构建、9 项前端测试、223 项 Python 单元测试通过。本轮浏览器连接超时，尚未做实际点击下载验收。
- 上述状态对应 2026-10-02。2026-10-03 已实现同页业务看板与多维透视，详见 [看板与透视 MVP](budget-view-analysis-mvp.md) 及 [交付验收](budget-analysis-acceptance.md)。
