# 下一年预算：可用版本与验收边界

日期：2026-10-12

## 使用路径

入口：`/budget/next-year`。顶部模块切换固定为“查看预算 / 达成预测 / 下一年预算”。

1. **目标与范围**：选择真实可用财年和已确认预测，手工填写经营目标；可增加校区、产品和业务组合。
2. **入口人数**：选择一个或多个入口年级，按年级或具体业务分配入口人次；可锁定具体业务。
3. **招生参数**：筛选赛道、校区、产品、年级、科目、季度后批量修改，或粘贴表格数据；设置允许调整的上下限和锁定项。
4. **资源与财务**：维护价格、折扣、结转比例、最低成班人数和计划班额，查看季度班量。
5. **预算概览**：看板与透视共用同一套筛选，可下钻明细；支持手动调节和按经营目标自动调平。

修改后先预览“修改影响对比”，再保存。保存追加一个草稿版本。版本记录支持只读回看、版本比较、恢复为新草稿。

## 计算与数据边界

- 经营目标只能由用户指定，不把上一年预测收入当作下一年目标。
- 已确认预测、原预算和历史草稿均不覆盖。预览、影响对比和调平预览不写版本账本。
- 恢复历史版本使用该版本冻结的来源、输入和结果，追加新版本，不替换原历史记录。
- 复用现有人次、收入计算及优化 evaluator / solver；正式定版、升年级、毕业和停科规则不变。
- “最低成班人数”仍是原有校验参数；新增“计划班额”专用于 `ceil(人次 / 计划班额)` 班量测算。未填写时保持未知，不按零班量展示。
- 自动调平尊重锁定、入口总量、参数边界和现有成班约束。有限搜索未找到候选不等于全边界无解；部分改善不宣称达标或最优。
- 新业务没有历史招生事实，不能伪造历史权重、期初老生或结转；参数可参考已有模板，人数由用户明确输入。
- 财年目录只显示有真实来源或已有草稿的财年；当前可用来源是 FY27 已确认预测，预算是 FY28。当前不伪造 FY29 数据，也未支持同年重编预算。
- 本次提供下一年预算的独立草稿流程，没有新增或绕过正式发布入口。

## 复制与导出

- 所有表格提供“一键复制”；明细提供 XLSX 导出。
- 分页表格复制、导出的是筛选后的全部明细，不仅当前页。
- 续班率、折扣为数值型百分比，金额和人次为 Excel 数字单元格；标识符、空值和原负数不随意转换。

## 验收方式

- 后端使用独立临时账本和测试数据，覆盖预览无写入、版本追加、恢复不覆盖、并发/幂等、参数校验、调平约束与影响计算。
- 前端覆盖编辑、批量参数、历史只读与来源、复制导出、未知班量和失败状态。
- 真实页面只做未保存预览与回看；核验批量参数影响、班量、多入口年级和全量明细传输，结束后放弃预览。
- 交付前核对账本文件数量、修改时间和正式预算数据库指纹，确认没有追加验收版本或修改已有定版数据。

## 成班约束后续诊断（2026-10-12）

上一轮功能已提交并推送为 `3eeaa4afb04c2f42e1894ef2a8fe823a8f60bd52`。

390 条全部是逐季度人数低于最低成班人数，涉及 121 个业务组合；不是四季全零、停科映射、负数结果或重复告警。按暑假、秋季、寒假、春季分别为 70、93、106、121 条。其中 78 个组合带冻结期初结转，不能直接关闭并丢弃金额。

确定的实现错误是把收入贡献归因中的 `r00/r10/r01` 对照计算当作最终候选硬约束。按既有 ADR-0147，对照计算只需完整、可计算；最终 `r11` 仍必须通过全部成班、比例边界、折扣与目标校验。缺人数、参数或结转等不可计算错误仍阻断，不按零代替。

保守上下界复验命令：`.venv/bin/python -m scripts.diagnose_next_year_class_bounds`。该检查不写输入、经营目标、账本或数据库：

- 固定入口、当前默认 ±5 个百分点范围：至少 234 条 / 74 个组合始终不足成班。
- 原预览入口 ±20% 窗口：至少 212 条 / 69 个组合仍不足成班。这是旧预览窗口，不把它描述为正式规则的硬边界。
- 即使把入口独立上界放宽到财年总量，故意忽略各行入口之和的联合约束，仍至少 166 条 / 52 个组合不足成班。这个更宽的空间仅用于不可能性检查，不是可应用的入口分配方案。

这些只是不可行项目数量的保守下界，不是建议补足的人数，也不是最优性证明。系统不得静默补人、降最低人数、扩大容差、解除锁定、跨维度凑班，或用关闭范围丢弃结转。

用户已选择“保留全部业务，生成 FY28 招生目标及参数边界的整体调整建议，预览确认后保存”。这授权生成草稿建议，不把建议人次当成来源实际，不代填经营目标，也不自动保存。系统先展示入口重分配、计划新生目标及必要边界变化，用户通过“应用并预览”接受后，沿用“保存并重算”追加新版本；原 N8 不覆盖。

## 成班方案与调平验收

入口：预算概览 → **检查开班范围** → **生成成班方案**。未填写经营目标也能检查和生成建议。候选与当前输入分开显示，取消不丢编辑内容；“应用并预览”只更新未保存输入，保存才追加新版本。历史版本只读，不使用当前来源重新生成建议。

真实 N8 的候选结果：

- 390 条成班问题 → 0；233 个启用业务全部保留，入口总量仍为 10,000。
- 固定入口总量内调剂 63 人次；97 项入口输入被明确固定，其中部分只是保留原分配，不重复计为新增人次。
- 建议 527 项明确的新生招生目标；全年新生净增加 2,495 人次，其中 1,066 是避免取整及后续参数调整再次不成班的预留。另列 308 项参数边界建议及 6 项超过历史入口 ±20% 参考窗口的偏离。
- 候选全年收入 12,150.64 万元，总人次 41,866（老生 25,288、新生 16,578）。这是按建议招生任务计算的预算，不是实际招生承诺或自动设置的经营目标，也不宣称最少补人或全局最优。
- 调平预留的范围安全证明仅限入口分配固定、当前显式比例范围（未设边界时为默认 ±5 个百分点）及现有锁定项。不能证明整个范围安全时，单独展示原因；当前合法方案仍可预览，后续调平必须重新通过完整校验。

交互搜索复用原有优化器和水位构造。精确求解预留时间给完整内核验证的有限搜索；先搜索共同水位及单类参数，再做粗到细网格。部门原有 1 万元容差按赛道分摊搜索，避免“各赛道分别达标、部门合计超差”。有限搜索失败或部分改善仍如实显示，不放宽最终约束。

仅内存验收目标（未写入真实 FY28 经营目标）：候选基础上上调 20 万元，差额 3,217.03 元；下调 20 万元，差额 6,694.60 元。两者均在原 1 万元容差内，全部成班校验通过。不可据此推断任意经营目标均有解。

页面验收已验证生成、应用为未保存预览、成班复核为 0、放弃恢复 N8，以及重新生成待审核方案。已导出全部 390 条成班问题、527 条新生目标，确认人次及预留列为 Excel 数字单元格。复制按钮状态与前端传输测试通过；本轮内置浏览器的剪贴板读取返回空值，未把这项当作全量剪贴板内容的独立验证。
