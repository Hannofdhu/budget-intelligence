# 看板与透视：本机交付与验收

日期：2026-10-05。状态：本机实现、自动验收及主要浏览器交互验收完成；下载落盘仍有工具验证边界。范围：预算结果的只读浏览，不涉及预算重算、调平、确认或发布。

## 入口与使用路径

- FY27：`http://127.0.0.1:5188/budget/workspace?archive=fy27&step=5`。
- FY28：在年度选择中选择 FY28，打开第五步“预算概览”。
- 五项任务导航和年度上下文保留；“看板 / 透视”就在概览内切换。
- 看板平铺收入、老生、新生、总人次和季度预算续班率；透视用于自行组合维度和指标。
- 顶部筛选影响当前整个视图；选一个金额只展开该格的构成明细，不偷偷重设顶部筛选。
- 导出区分“当前透视”“全部范围明细”和“所选明细”；不会只导出当前分页。
- 个人视图仅保存当前浏览器的筛选和布局，不保存预算金额、不产生预算修订。

## 复用与范围边界

FY27、FY28 共用 `BudgetAnalysisView` 与 `budgetAnalysis`。两个读取适配器分别读取历史保存值和已发布版本，不把历史金额当成新预算计算结果。

FY28 老生、新生来自收入结果所依赖的具体人数版本，不能读取最新但不属于这版收入的人数结果。关联不完整或不兼容时显示“—”，不使用新生比例推算、不补零。

FY27 保留本机访问限制；本轮不扩大局域网授权、不部署内网。2026-10-05 已按用户要求先将改造前项目快照推送至既有私有 GitHub 仓库（d389b0d），原始 Excel、提取快照和运行目录未上传。本轮新增改造仍在本机，尚未再次推送。

前台不增加“查看依据、来源与口径、参数来源”等技术入口。内部来源快照、校验和审计保留。
