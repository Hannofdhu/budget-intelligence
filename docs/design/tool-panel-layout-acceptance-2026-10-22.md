# 工具面板无遮挡修复

范围：统一现有工具面板布局，不新增工作台、预算编辑流程或草稿存储，不改接口、计算、预算输入、保存和定版规则。

## 布局契约

- 宽屏（不小于 1440 CSS px）：正文与右侧工具分配独立空间，间距 24px，工具内长表独立横滚。
- 窄屏（严格小于 1440 CSS px，包括缩放产生的小数宽度）：工具回到文档流，不覆盖正文；标题和关闭入口可达，关闭归还入口焦点。
- 一般查看和编辑工具为非模态，可回到正文对照；离开未保存内容等风险确认仍为原生模态对话框。
- 高层版本/核对工具暂时占用同一位置时，不丢弃原工具中的输入；关闭后原工具可恢复。不会生成或保存预算版本。
