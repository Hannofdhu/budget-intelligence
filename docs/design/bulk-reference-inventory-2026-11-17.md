# 批量编辑参考数据覆盖扫描

日期：2026-11-17。只读扫描前端复制、模板、粘贴及批量操作实现，并核对当前路由。未调用真实业务写入接口。

## 活跃路径

| 位置 | 当前能力 | 本轮处理 |
| --- | --- | --- |
| `NextYearBudgetPage` → `NextYearBulkPanel` → `nextYearBulk` | 7类对象共用“复制编辑模板 → Excel分别填写 → 粘贴校验并应用” | 全部模板增加判断所需的只读参考列；识别身份、参考、编辑三种角色，只写编辑列 |
| `NextYearBudgetPage.nextYearParameterTemplate / parseNextYearParameterPaste` | 保留的原双率值模板兼容工具；活跃UI已调用共用批量核心 | 兼容旧模板，不另开一套编辑入口或保存流 |
| `WorkspacePage` → `RateTableEditor` | 勾选后统一设置当前比例/上下限，无Excel粘贴写回 | 原表及一键复制/导出已有历史参考、当前值、允许上下限、依据、锁定和确认状态，无缺失的编辑模板 |
| `ActionTable`、`QuarterlyBusinessTable`、各模块明细表 | 普通一键复制和结构化明细导出，无粘贴写回 | 保持既有完整源字段和独立维度，不把普通导出误称为编辑模板 |
| `BudgetAnalysisView` | 透视复制/导出，无预算编辑写回 | 无新增编辑模板 |
| `AiAgentPage` | AI终端文本粘贴、问题复制 | 非预算表格写回，不适用 |

结论：截至本次代码扫描，产品中可导出后再粘贴写回的活跃业务模板只有共用预算编制批量编辑流程。一次扩展7类对象即可覆盖当前所有同类模板。普通表格复制/明细导出与写回模板保持各自语义。

## 最小判断依据建议

| 编辑对象 | 应随模板提供的参考 | 真实粒度与边界 |
| --- | --- | --- |
| SKU参与预算 | 来源标签、上一财年结转收入和招生人次及经营基础状态、本财年暑假老生和承接状态、期初结转、当前入口/参与状态 | 与同一SKU主表及草稿绑定基准一致，财年动态 |
| SKU入口 | 当前入口属性、当前参与状态、指定/分配人数、分配依据或权重、部门入口总量、期初结转 | 全SKU，不把部门总量误当当前筛选总量；分配待重算时不得输出旧值为当前值 |
| 续班率及新生占比 | 当前两种率值及允许范围、当前新/老/总人次、结果状态 | 校区、赛道、产品、年级、季度共享，按真实结果键去重聚合，不重复累计科目或季度 |
| 自动调平范围 | 当前两种率值、已有上下限、锁定状态、当前人次及结果状态 | 与比例参数相同粒度，未显式设置的范围须区分默认/未设置，不能伪造为已保存值 |
| 财务参数 | 当前学费、折扣、当季结转比例，当前新/老/总人次及结转收入、结果状态 | 完整SKU和季度，保留原金额精度和清楚单位 |
| 计划/手动新生 | 当前计划值、当前新/老/总人次、人工锁定及原因、结果状态 | 完整SKU和季度，保持原适用范围，暑假入口不覆盖 |
| 班均 | 当前班均、全年人次/班量、未达班均项数或状态 | 赛道、产品共享；全年指标明确标“全年”，不能因页面校区/科目筛选而伪称仅影响筛选SKU |

参考字段仅来自现有输入、计算结果和已绑定预测基准；本轮不新建指标算法、请求口径或管理工作台。

## 数据和写回约定

- 身份列保持独立原始维度，不解析展示合并字符串；参考列不参与身份匹配。
- 参考列即使被使用者修改，也不得进入预算写回；编辑列白名单沿用既有字段和校验。
- 真零保留0；未知、读取中、读取失败、数据不全、未参与预算和待重算分别用状态表达，数字列留空。不得把未读完的数据填成0。
- SKU `historyRevenue/historyStudents` 与现有 `nextYearSkuDetailRow` 一致。`empty`若证据确为0则保留0；`missing`为null。两者可共用“无同年级经营基础”展示状态。
- 当前结果若因未保存输入而失效，应给空值和待重算状态，不把旧保存结果作为当前判断依据。
- 表头须区分参考和可修改列并给单位；旧模板可兼容，但不得以兼容为由接受未知或重复可写字段。

## 第一轮独立实现审核

已核对本轮共用核心、面板、父页传入上下文及既有SKU明细投影。参考列按明确角色生成，匹配仅取独立身份维度，写回仅取编辑字段；父页传入草稿绑定证据、动态财年和待重算状态，无新增数据接口。

独立内存夹具验证通过：

- FY33/FY34标题随来源与目标财年变化。
- 历史证据读取中为数字空白及“读取中”，已证实空槽真零保持0。
- 篡改全部只读参考单元格后粘贴，仅编辑列生效，参考金额、部门入口总量与原输入对象保持不变。
- 班均共享组重复同一SKU季度结果行时去重，不重复累计人次或班量。
- 待重算结果数字留空并有明确状态。
- 发现班量为null时原统一结果状态可能显示“已计算”，已反馈并由核心实现补充独立“班量结果状态”；修正后独立夹具验证“全年班量”空白且状态“数据待核对”。
