# 预算编制批量编辑推广验收

日期：2026-11-17。沿用 `DESIGN.md` 11.3 / 11.3.1、现有单页五步、工具面板、改动清单、预览与保存新版本流程。

## 交付范围

| 原业务位置 | 批量字段 | 真实作用粒度 |
| --- | --- | --- |
| 定目标和SKU → SKU | 参与预算、不参与预算 | 校区、赛道、产品、年级、科目，全年生效 |
| 入口新生定多少 → SKU入口设置与分配 | 是否入口、指定入口人次、恢复自动分配 | 完整SKU的暑假入口，部门总量不变 |
| 续班率、新生占比 | 保留原双率值能力及既有Excel模板兼容 | 校区、赛道、产品、年级、季度，共用全部科目 |
| 调平范围 | 两种率值的上下限 | 同招生比例粒度 |
| 计划新生及预算手动调节 | 计划新生、手动指定新生 | 完整SKU、季度；暑假入口不覆盖 |
| 财务参数 | 学费、折扣、当季结转比例 | 完整SKU、季度 |
| 班均 | 班均 | 赛道、产品，共用全部校区、年级、科目、季度 |

各区块入口复用一个受控面板。统一设值与Excel分别设值作用于当前筛选的完整适用范围，不限分页。恢复自动分配是显式动作；空白表示不改，0是实际输入。模板身份维度独立，不解析界面组合名称。

## 规则与未保存改动

- 复用 `applyNextYearEdits` 的既有精度和数值校验，补齐与既有后端一致的期初结转、入口总量/分配依据及显式上下限检查。
- 整批校验失败不改变输入或原改动；错误在面板内说明，保留可纠正的模板。
- 年级入口分配与SKU指定人数、计划新生与手动新生写入同一物理字段时，保留其他已投影改动并清除冲突路径，避免旧输入覆盖新批量值。
- 应用进入原改动清单。班均或人次变更后既有结果标记待重算，仍由底部查看影响和保存新版本处理。合法未变化模板不制造改动或清除已有预览。
- 本轮未新增后端接口、预算编辑流程或保存入口；未改预算算法和定版规则。
