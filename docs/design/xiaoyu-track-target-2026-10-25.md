# 小予讲解：分配赛道目标

## 已核实的真实逻辑

读取 `NextYearBudgetPage.tsx` 的 `distributeTargets` 与 `nextYearApi.ts` 的 `allocateNextYearTrackTargets`，并对照下一年预算生成、修改、收入汇总路径：

- 全年目标取当前输入框：优先使用未保存编辑，其次使用预算输入中的值。
- 分配比例取该预算已保存版本的 `draft.calculation.tracks[].revenue_yuan`。这是按预算招生、学费、折扣、结转及税务参数算出的预计收入，四季按赛道汇总；不是FY28实际收入，也不是直接套用FY27全年预测收入比例。
- 原编制基准仍是预算绑定的已确认全年预测。生成预算时由其准备期初人数、收入等参数，后续修改保存用预算自身参数重算；不自动切换最新预测。
- 未保存招生或财务修改、新预览和手工填写的赛道目标不作为分配比例，页面筛选不缩小分配范围。
- 缺失、无效或负收入按0作分配权重；全部为0时均分。先将全年目标四舍五入到分，再以最大余数法补分，余数相同按赛道名排序，保证合计等于取到分的全年目标。
- 按钮覆盖本页赛道目标，其他修改保留，旧预览清除。不会改变招生或收入，不会调用自动调平，不保存新版本。

保持既有分配规则，仅接入讲解；不替用户决定改为上一财年预测占比。
