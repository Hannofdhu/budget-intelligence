# 小予在真实产品中的接入

2026-10-24，本机开发版本。以当前 `/budget/ai` 的聊天工作区为准；该路由使用 `AiChatPage.tsx`，不是旧终端式 AI 页面。

## 位置与形式

| 位置 | 呈现 | 触发与目的 |
| --- | --- | --- |
| AI 新对话首页 | 128px迎接姿态；手机88px | “我是小予，陪你看结构、查差异、找下一步。”保留原问题建议与输入框 |
| AI 首段回答等待 | 48px思考姿态；手机40px | 真实准备／运行状态且正文为空。排队改核对姿态，停止改提醒姿态；开始输出正文即收起 |
| AI 对话读取 | 小型核对姿态 | 选定对话正在读取且尚无记录显示 |
| AI 后台结果到达 | 完成／提醒姿态＋结果通知 | 根据 completion 状态选择；完成只表示回答任务结束，仍需核对回答内容 |
| AI 连接／运行环境不可用 | 提醒姿态＋原错误文字和重连按钮 | 保留错误详情和恢复操作 |
| FY28 没有来源预测的首次入口 | 96px核对姿态 | 引导先确认全年预测；已存在草稿时不出现 |
| FY28 保存反馈 | 48px完成姿态 | 仅“已保存为新版本”提示；暂存、预览、待重算不使用完成姿态 |
| FY27 全年预测保存／确认反馈 | 48px完成姿态 | 仅“新预测已保存”“预测已确认”提示 |
| FY28／全年预测操作失败 | 提醒姿态＋错误说明和原操作 | 不遮挡原因、诊断信息、保留版本说明或重试按钮 |

AI 同一视图只突出一个小予：连接问题优先，其次后台结果通知，最后消息等待／欢迎。其他状态文字不隐藏。顶部保留产品 Logo，表格、KPI、透视、明细、导出数据没有加入吉祥物。当前为静态插图，无循环动画、额外浮层或新增网络接口。六种姿态为本地 SVG；休息姿态保留为备用素材。

## 验证与状态边界

- 前端757项测试通过，另补充了队列／运行／停止、输出正文后收起、待核实／失败／中断不显示完成姿态、本地SVG资源完整性等检查；关闭等待插图时，等待文字仍保留。
- TypeScript与Vite生产构建通过；构建仍提示现有大体积chunk，可独立处理。
- 真实AI欢迎页在1440×900、390×844、320×740检查；图片正常加载，无页面横向溢出，输入框可用。手机首次进入默认收起历史列表。
- 使用独立测试标签页，通过CDP拦截GET响应，展示模拟的运行、后台完成和503失败状态；检查真实页面组件，并未发送问题或调用模型。390px下角色为40px，无横向溢出；错误和完成通知并存时仅错误提示显示小予，等待文字继续保留。
- FY28正常页面实时读取到第23版、已保存草稿、改动0项，正常看板中没有吉祥物。另用隔离GET失败响应检查了预算读取失败提示、图形加载和重新读取／关闭操作的保留。
- 没有执行预算预览、重算、保存、预测确认、恢复版本或AI发送。保存成功插图已接入对应成功分支，未通过真实写入预算来触发验收。无来源预测入口、全年预测失败／保存反馈未做实时业务操作验收。
- 所有临时接口拦截已清除，模拟标签页关闭；无后端规则或接口改动。本次未发布生产环境。
