# 预算智解统一设计规范独立审核记录

日期：2026-10-14。审核对象：[统一设计规范](../../DESIGN.md) 与 [苹果规范研究依据](apple-hig-research.md)。

结论：修订版无剩余阻断，可作为 1.0 文档基线。规范覆盖现有主要交互，内部一致，能够复用当前组件渐进实施。该结论不代表产品页面已迁移、CI 已通过或全站无障碍达标。

## 1 审核独立性与范围

一位子代理专门负责全面审核，未参与规范起草或文件修改。它先独立检查仓库和官方设计原则，再全文审阅 0.9 草稿，提出问题，最后重新全文审阅修订版。另一位来源核验代理单独核对苹果和 W3C 原文、尺寸归属和颜色算术。文件均由主代理集中修订。

审核覆盖四模块和五步导航、SKU 对应区块、只读与编辑、专业表格、复制导出、保存版本、预测快照、AI 边界、键盘输入法、辅助技术、响应式以及逐批验收。不使用真实预算写入或确认操作作为审核手段。

## 3 保留的工程约束

- 共用 Header、BudgetPageNavigation、BudgetScopeBar、ActionTable、季度布局和高度测量，不引入平行 UI 框架或另一套编辑流程。
- FY27 定版只读、FY28 历史只读和角色权限不变；查看影响、保存、确认、定版的业务边界不变。
- FY28 经营目标继续手动指定；基准使用精确已确认预测及快照；刷新失败不覆盖旧结果。
- 已有计算精度、合计口径、复制导出范围、表格键盘与中文输入法保护不被视觉迁移改变。
- 固定提交栏保留为 Web 产品取舍，但必须验证高度、安全留白、焦点、软键盘和低矮窗口；不因苹果 macOS 建议再加重复保存按钮。
- AI 外层一致，但保留 Pi 终端和既有权限隔离，不获取产品源码、凭证或预算写入权限。

本轮只新增三份规范文档，不修改页面、组件、样式、后端、预算数据、计算和定版规则，不提交或推送 GitHub。

文档的来源归属、相对链接、结构和颜色计算已检查；代码测试、CI、浏览器视觉与辅助技术的产品验收留待真实组件迁移时执行。本次没有把文档审核包装成产品验收。
