# 预算编制明细导出扫描表

日期：2026-11-16。范围：`NextYearBudgetPage.tsx` 与 `QuarterlyBusinessTable.tsx`。

前端继续使用现有紧凑身份、双行指标、季度对照和版本卡片；分析导出直接从原对象取字段，不拆展示字符串，不改变数据读取、计算、权限或保存入口。整表复制使用同一份全筛选范围投影；复制所选仍按前端视觉单元格执行。

已覆盖 20 处 `PagedTable` 调用、1 处维度汇总 `ActionTable`、2 处季度对照调用。分页组件内部的通用 `ActionTable` 不重复计入业务位置。

| 位置 | 原展示中的合并 | 分列导出 | 数据及状态边界 |
| --- | --- | --- | --- |
| SKU 主表 | 校区/赛道/产品、年级/科目、经营基础、承接基础 | 校区、赛道、产品、年级、科目、来源标签、上年结转收入（元）、上年招生人次、经营基础状态、本年暑假老生人次、老生承接状态、期初结转（元）、入口、参与预算，共14列 | 44条统一空态仍显示同一句；其中真实0在数值列保留0，未核准或缺失数字留空；原始元精度保留 |
| 年级入口分配 | 指定人数的输入/显示混合 | 年级、指定人数、输入状态、原始输入、已分配人数、入口SKU数、分配结果状态 | 分配待重算时数值空、状态独列；指定输入与旧计算不混用 |
| SKU 入口分配明细 | 双身份列及输入格 | 五维、入口、指定人数、输入状态、原始输入、已分配人数、结果状态、分配方式 | 入口勾选、当前权限和编辑操作保持；非入口无结果不补0 |

| 招生参数逐季表 | 校区/业务 | 五维、季度、续班率及适用/输入状态/原始输入、新生占比及适用/输入状态/原始输入、锁定 | 共享参数没有科目时留空；不按其他SKU补科目；不适用率值留空 |

| 财务参数逐季表 | 双身份列 | 五维、季度、学费（元）/折扣/当季结转，各含输入状态和原始输入 | 维度按原 `combination_id` 对应；合法Decimal保留，不用展示值四舍五入 |

| 班量计算明细 | 双身份列及格式化结果 | 五维、季度、人次、人次状态、班均或历史班量基准、班量、结果状态、开班状态 | 冻结历史口径保留；人次/班量各自按现有待重算条件置空并注明 |
| 手动调节明细 | 双身份列 | 五维、季度、当前新生及状态、指定新生及输入状态/原始输入、锁定 | 只导出当前范围；仍需现有预览和保存流程 |
| 预算明细表/页头导出 | 双身份列、展示金额 | 原有独立五维、季度、老生、新生、总人次、元金额、单价、各率值、班量及开班状态 | 导出显示中的已保存计算或真实预览；既有待重算禁用条件保留 |
| 维度预算汇总 | 万元展示值 | 赛道或校区、原元收入、原元目标、原元差额、人数 | 汇总表使用已有筛选行与目标来源，导出不再读万元显示文本 |

| 财务参数季度对照 | 单个业务格、指标纵排 | 五维 + 每季度学费、折扣、当季结转及各自输入状态、原始输入 | UI原3个指标行不变；无效数值空、原输入保留独立列；缺季不补0 |
