# 「解构之窗」Logo 产品接入

2026-10-23，接入用户选定的第一版 Logo。本次为本机运行产品的前端品牌接入，未部署或推送远程环境。

## 配置位置与形式

| 位置 | 形式 | 实现 |
| --- | --- | --- |
| FY27定版预算、全年预测、FY28预算编制、AI智解顶部 | 透明底图形＋中文名；桌面32px、窄屏28px | `FY27Header` 使用 `BudgetBrand`，原导航、回首页、离开保护不变 |
| 年度预算工作区、期初老生、调平、变化记录与发布入口 | 同一图形＋中文名，含加载／未连接状态 | `BudgetContextHeader` 与原入口复用 `BudgetBrand` |
| 浏览器标签页与书签 | 纯图形 SVG；深色偏好下方框反白 | `index.html` 引用 `/brand/favicon.svg` |
| AI 未开始对话的提示区 | 40px图形＋“预算有据，决策有解。”与原开始提示；窄屏32px | 使用 `BudgetMark`；已有会话仍展示原终端 |

Logo 采用固定的两片路径：墨黑方框 `#141413` 与陶土橙模块 `#d97757`，对应 Figma 第一版：[解构之窗](https://www.figma.com/design/urVasakXpz8irlxdEVlAUE?node-id=2-2)。SVG 本地随构建发布，不依赖 Figma 或外部图片服务。导航保留现有中文功能字体，不增加英文副标题；图形在文字组合中为装饰，避免重复朗读。

业务表格、结果数字、版本状态与导出数据继续以业务信息为主，不加 Logo 水印或修改文件内容。没有新增安装入口、应用清单或报告封面。

## 已验证

- 完整前端测试720/720通过；TypeScript及Vite生产构建通过；保留既有大体积chunk提示。
- 真实Chrome：预算编制与AI桌面显示正确；四个主模块390px下标识加载、中文名和当前模块保留，无整页横向溢出；预算编制、全年预测320px下也无整页溢出。
- 期初维护及调平／变化记录／发布的未连接入口390px下标识正确；未连接预算修订，不触发读取维护数据、生成方案、发布或保存。
