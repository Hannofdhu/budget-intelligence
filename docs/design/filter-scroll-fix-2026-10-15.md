# 筛选器展开跳页修复验收

日期：2026-10-15。基线：`4883761`。范围仅为共用筛选浮层、焦点及回归测试，不修改预算数据、计算、权限或定版规则。

## 复现与原因

通过 Computer Use 在真实 FY27 查看预算页面展开“赛道”筛选，`scrollY` 从 0 变为 4079；筛选触发点移到视口外，菜单随之定位到视口外。

旧组件首次展开把菜单 portal 插入正文尾部，初始定位样式为空，随后才通过 layout effect 的状态更新赋予 fixed 定位。该更新可能提前刷新被动 effect，菜单还在正文流中时就执行默认 focus，浏览器因此把文档滚到末端。之后的定位提交不会恢复阅读位置。

原合成测试的 focus mock 只设置 activeElement，没有模拟 CSS、浏览器滚动或两次提交时序，因而不能证明真实几何行为正确。

## 修复

- 菜单首帧即为 fixed，在 layout effect 中同步完成几何定位后再聚焦，不再用第二次状态提交补定位。
- 打开、Esc/Tab 归还和键盘导航使用 preventScroll；仅修改菜单自身 scrollTop 来显示活动选项。
- 长列表最大高度限制为实际展开方向的空间；重新定位显式清除另一侧 top/bottom。
- 保留原多选、值匹配、对话框 portal、外部关闭及筛选 URL 行为。
