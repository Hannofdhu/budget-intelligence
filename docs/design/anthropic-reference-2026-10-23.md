## 2 品牌参考：采用与不采用

官方品牌 Skill 给出深色 `#141413`、浅色 `#faf9f5`、中灰 `#b0aea5`、浅灰 `#e8e6dc`，以及橙 `#d97757`、蓝 `#6a9bcc`、绿 `#788c5d` 等颜色；标题采用 Poppins、正文采用 Lora，分别回退到 Arial／Georgia。v1.2 将其作为目标品牌体系，语义角色和中文适配由本产品规定，运行时尚未变更。

| 可借鉴的方向 | 预算智解的具体取舍 |
| --- | --- |
| 温和中性色与清晰深色文字 | 采用官方暖白／深色／灰色，次要文字和必要控件边界补充可读性功能色 |
| 有限而有目的的强调 | 陶土橙替换旧深绿主强调，当前步骤采用深色；警告／错误不与品牌角色混同 |
| 字体有分工 | 标题 Poppins、叙述 Lora；中文回退和密集功能区例外见第 4.1 节；字号、字重和等宽数字要求保留 |
| 视觉安静、内容有秩序 | 减少无意义包裹，用对齐、间距、分隔组织，保留必要输入边界和表格密度 |

官方色板中的浅灰不能未经对比度验证就用作小号正文；品牌橙也不天然等于警告。语义映射以 `DESIGN.md` 第 4.2 节为准。静态计算发现白色文字配陶土橙约 3.12:1，故主按钮选深色文字；官方橙／蓝与暖白约 2.96:1／2.78:1，不能直接作为需达到 3:1 的关键边界或数据线。本次未修改共享令牌、下载字体或引入品牌图形资产，不代表实际状态组合均已验收。

## 2.1 字体覆盖与分发依据

[Google Fonts 的 Poppins 元数据](https://github.com/google/fonts/blob/main/ofl/poppins/METADATA.pb)列出的字符子集为拉丁字母及天城文等，[Lora 元数据](https://github.com/google/fonts/blob/main/ofl/lora/METADATA.pb)列出拉丁、西里尔等子集，均不含中文。故中文必须使用明确的回退字体，不能只改 CSS 字体名称后宣称中文已使用官方字体。

本产品选择标题中文黑体类回退、叙述中文宋体类回退；密集表格／表单／按钮／数字区采用 Poppins 加中文无衬线回退，避免把操作界面整体变成衬线长文。这些是项目适配，不是官方中文规范。

后续实施从可追溯字体来源自托管分发，并随字体保留版权及许可文件；来源见 [Poppins OFL](https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt)、[Lora OFL](https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt)。不依赖用户安装，不通过第三方字体 CDN 保证主要界面，不随产品复制系统中文字体。本次未安装、下载或重新分发字体，正式实施时仍需核对具体资源与许可。

## 3 方法参考：从任务到视觉，而非从皮肤到页面

frontend-design 的价值在于设计选择有上下文：先明确用户任务和内容，再决定排版、色彩及布局，并检查结果是否真的适合这项任务。其对模板化设计的警惕同样适用于暖白、衬线和低饱和色，不能因为用户喜欢 Anthropic 就机械复制这一套外观。

项目据此形成第 15.7 节的交付顺序：任务与不变项 → 信息结构 → 视觉选择 → 三类代表性样板 → 共享组件推广 → 状态与浏览器验证 → 准确记录完成边界。这是预算智解自己的实施约定，不是对官方方法的逐条翻译。

## 4 实际产品依据

2026-10-23 对当前用户已打开的 FY28 预算编制第 5 步做了只读观察：页面为第 23 版、已保存草稿、改动 0 项，春季明细筛选仍在；没有导航、编辑、计算或保存操作。观察到模块／步骤、全年总览、当前 SKU、多维筛选、明细工具和固定提交栏的不同职责，需要分别处理视觉强弱，不能统一卡片化。

源码核对范围：

- `apps/web/src/budgetTokens.css`：现有中文系统字体、绿色品牌、字号角色、间距和层叠令牌。
- `apps/web/src/BudgetAnalysisView.tsx` 及现有明细展示：SKU 身份分组、金额／率值、复制与导出的业务语义。
- 原规范第 5、6、7、11、14 章：共用组件、专业表格、编辑保护、面板布局及版本引用要求。

由此确定的适配重点：

1. 中文优先：长校区、年级／科目和业务版本名称完整可读，标题与表格角色分明。
2. 比较优先：数据表保留行列关系、数值对齐和跨季度比较，不用大留白挤掉数据。
3. 范围明确：全年、部门入口、仅受校区影响的汇总与当前 SKU 不能因外观统一而混成同一范围。
4. 操作可信：选中、未保存、待重算、历史只读和失败反馈都有准确文字，现有保护不降级。
5. 组件收敛：从共用令牌、表格和工具面板改善，不靠逐页覆盖 CSS 追求截图相似。

这些是适配理由，不是“当前全部页面已无问题”的结论。原截图展示的历史业务值不作为未来固定验收值。
