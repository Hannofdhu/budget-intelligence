# 产品全屏入口验收

日期：2026-10-26。范围仅为共用顶栏的展示控制，不改预算数据、计算规则或 AI 调用流程。

## 交互与设计

- 五个模块共用右上角“全屏”外框按钮，沿用现有功能字体、暖白底与边框令牌。
- 用户点击后通过浏览器 Fullscreen API 全屏显示整个产品，按钮改为“退出全屏”；支持再次点击及原生 Esc 退出。
- 以浏览器实际状态为准，不自动进入、不刷新页面、不改变浏览器缩放，不重新挂载产品正文。
- 不支持或请求被拒绝时明确提示；快速重复点击只发出一次请求。离开页面只移除监听，不主动停止 AI 或执行预算动作。
- 顶栏上下文允许换行；1100px 及以下使用共用双行导航，反馈出现时第一行可增高。窄屏保留按钮文字、财年、草稿状态与版本，不与模块切换重叠。

## 验证

- 浏览器：在独立 Chrome 标签实际进入全屏，按钮切为“退出全屏”；通过按钮退出及原生 Esc 退出后均恢复“全屏”。后台标签被浏览器拒绝的请求显示失败提示，不显示伪成功。
- 输入保护：填入“全屏切换验收文字（不发送）”，切换全屏后文字仍在；验收完已清空，未发送消息。未操作原对话的发送、停止或预算保存按钮。
- 窄屏与临界布局：实际 CSS 视口 320px 和 1001px 检查通过，按钮、财年与版本可见，模块导航位于其下；临时视口覆盖已恢复。另检查了普通桌面布局。
- 预算页面只读检查：FY28 编制仍显示第30版、已保存、草稿、改动0项。未点击预览、调平或保存。
- 前端全量测试：833 项通过，包含9项新增的全屏与公共入口用例。类型检查及生产构建通过；构建仍提示既有大资源包告警。
