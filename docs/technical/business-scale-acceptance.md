## 已实现

CP-SAT 线性约束在范围证明前做精确公约数约分。约分包含所有系数、常数及上下界，不截断金额、不四舍五入边界、不改变综合折扣容差。无公约数时保留原式；约分后仍不安全的模型继续返回 `INCOMPLETE / MODEL_RANGE_UNPROVEN`。最终解使用未约分原约束重新核验。

第二轮继续将除法约束的分子系数、舍入偏移常数及分母做精确公约数约分。完整保留整数商和半入舍入语义，最终仍用原表达式复核；不能约分的表达式不会被截断。适配器当前版本为 `ortools-cp-sat-9.15-v3`，用于区别旧求解实现。

## 合成规模

- 238 个组合、952 个季度记录；17 个合成校区，每校区 14 个合成科目。仅行数与历史规模对齐，不代表真实校区、科目或业务分布。
- 普通春季来源每组合 1,000 人次，期初续班率 80%，全年后续续班率固定为 100%，新生占比为零。第一季期初人次参与后续三季滚动。
- 基准收入 114,240,000 元；开放一个校区或三个校区春续暑续班率至 81%，目标分别为 114,324,000 元和 114,492,000 元，确保差额超过既有 10,000 元收入容差。
- 价格与数量均为合成输入，综合折扣目标为 100%，仍执行 0.05 个百分点容差。
- 候选须由正式人数、班均及收入内核复算，并返回 `OPTIMAL` 与目标达标；不是仅测试求解器接受模型。

## 第三轮：联合比例与亿元级 API

联合比例用例沿用 238 组合、952 季度行，在三个校区同时开放春续暑续班率和暑季新生占比。基准分别为 80% 和 20%，窄边界分别为 80.1% 和 20.1%；价格 120 元，全年基准 114,240,000 元。目标由确认边界端点的正式内核独立求值生成。校验两类比例均实际变化，各自同类参数跨校区等百分点推进，锁定值不变。两类比例是独立水位，不新增跨类型强制相等的规则（ADR-0070）。

宽边界试验将两类比例各开放 1 个百分点，每个受影响校区出现 `101 × 101 = 10,201` 个局部比例状态；三个校区再乘四组贡献复算场景，编译成本明显上升。该轮在长时间运行后主动中止，没有求解结论，不能算通过或不可行。窄边界降低的是合成测试复杂度，绝非替用户缩小业务确认边界；真实宽边界性能仍待解决。

API 用例 `tests/integration/test_opening_api.py` 保留原金额，并新增金额倍率 280：初始年收入 112,560,000 元，人数与确认比例不变。两种金额分别走冻结来源、期初版本、Worker 四阶段计算、独立端点目标、CP-SAT、应用、撤销、重新应用、正式确认和隔离发布，并继续检查幂等、跨部门拒绝与过期绑定。API 使用三条组合，不冒充 238 条组合的 API 验收。

API 验收两项通过，0 失败、0 跳过；亿元级用例 19.91 秒，原金额用例 19.59 秒。记录：`output/business-scale-api-tests.xml`。仅运行本地 `budget_acceptance_20260905_real` 隔离库；测试结束已停止本轮启动的 PostgreSQL，保留测试卷。未修改 FY27、未访问线上 BI、未发布真实业务预算。

第三轮单元/性质回归 222 项全部通过，0 失败、0 跳过；窄边界联合比例用例 39.03 秒，单一比例三校区 25.82 秒、单校区 9.89 秒。记录：`output/business-scale-tests.xml`。Ruff、格式检查及 mypy 通过。本轮新增测试及验收记录，没有变更正式业务算法或边界；未重跑其他数据库集成及前端构建。

## 第四轮：减少重复计算并约束建模耗时

- 每次局部人数内核调用只解析一次局部比例依赖，移出遍历全量比例列表的循环；不改变取整、收入或候选排序。
- 比例阶段及折扣阶段的直接求解路径，从建模开始计时，状态枚举逐项检查截止时间；求解器只获得建模后的剩余时间。超时返回 `INCOMPLETE / CP_SAT_BUSINESS_COMPILATION_TIME_LIMIT`，无候选，不报告不可行。
- 截止时间检查是协作式保护，不能中断正在执行的单次内核、原生库或排序；既有进程级硬超时仍是最终保护。本轮不能称为替代了进程级硬超时。
- 入口状态按范围乘积预检，超过原状态表上限即拒绝，不先展开巨大元组。比例状态按已生成的唯一状态计数，超过同一上限即退出；不截断搜索空间。
- 238 组合、三个校区、两类比例各开放 1 个百分点的宽边界，使用 0.2 秒直接建模预算验证返回未完成且无候选。这是失败安全验收，不是宽边界最优解验收；未缩小边界或放宽金额容差。
- 独立用例覆盖入口/比例枚举截止、两种直接编译器超时后不调用求解器、巨大入口范围预检及比例状态上限。

第四轮回归 227 项单元/性质测试全部通过，无失败或跳过。238 组合窄边界联合比例为 28.08 秒（第三轮为 39.03 秒，约减少 28%）；单类比例三校区为 17.19 秒、单校区为 6.75 秒。均为本机调用耗时，不是生产 SLA。Ruff、格式检查、mypy 通过；本轮未重跑数据库/API 或前端构建。

## 第五轮：局部内核结果复用

每次编译、每个取整组创建独立 LRU 缓存，最多 2,048 个结果。缓存键包含完整入口人次及比例取值，闭包绑定当前上下文与组合；不会跨校区、预算版本或编译运行复用。基准、仅续班变化、仅新生占比变化和共同变化都通过同一正式内核计算，命中时复用不可变收入结果。异常不被缓存。

新增对照验证：两类比例各两个值的四个状态，与无缓存计算逐值完全一致；贡献场景原需调用内核 16 次，缓存后为 4 次。不同财务上下文不会复用旧值，入口人次变化也会生成新缓存键。全部状态仍进入模型，没有以缓存为由删减搜索空间。

第五轮回归 229 项单元/性质测试通过，无失败或跳过。窄边界联合用例单独复测 20.77 秒；全量回归中为 21.54 秒，单类比例三校区为 11.21 秒、单校区为 4.54 秒。Ruff、格式检查、mypy 通过；未重跑数据库/API 或前端构建。

宽边界实际尝试：`scale_context(3, True, True)`，BALANCED 单 profile，直接比例求解器时间预算 60 秒，实际 60.017 秒，返回 `INCOMPLETE / CP_SAT_BUSINESS_COMPILATION_TIME_LIMIT`，0 候选。与本地回归并行运行，不能作为独占机器性能基准；它证明正常时间预算下会安全中止，不证明宽边界不可行或最优求解完成。后续应进一步削减二维状态表的编译成本，而非放宽容差或默认延长超时。

## 第六轮：二维档位分解与跨偏好模型复用（2026-09-09）

先计算各比例类型的档位结果，再对局部取值去重并组合。保留所有不同决策状态；触界后完全相同的局部取值只保留一次。1 个百分点边界下，单组仍有完整的 10,201 个二维状态，水位函数调用从 20,402 次减至 202 次。上下调、锁定、触界和外校区较宽边界均与原始笛卡尔积对照一致。

同一次求解的三个 profile 共享完成编译的局部状态表，重新生成各自的贡献偏离变量、约束和目标。逐项模型对照与独立编译完全一致；只复用同一不可变上下文、调节方向及状态行数限制下的完整模型。换上下文、方向、限制或新建求解运行均重新编译。未完成的模型不进入缓存。审计摘要增加 `reused_business_compilation`。
