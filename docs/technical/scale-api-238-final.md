# 238 明细 API 全链路验收

日期：2026-09-09。仅本地合成 FY28，不使用线上 BI，不替换 FY27。

## 用例边界

- 17 个合成校区，每校区 14 个组合，共 238 个组合、952 个季度记录。
- 七、八年级各含数学、语文、英语、物理、地理；九年级不含地理。来源为普通春季招生人次每行 100，验证升年级、九年级毕业及地理退出。
- 为聚焦 API 链路，固定总入口 1 人，仅首校区数学入口获得该人次；其他校区数学入口初始为零，其余七年级科目通过正式入口范围 API 排除。
- 84 条七年级明细通过计划新生 API 显式填写并锁定暑季 100 人。保留校区完整覆盖、零入口行、计划新生锁定及说明，不修改任何生产校验规则。计划新生不是调平变量。
- 每季标价 4,240 元，折扣 50%，税转换因子 1.06，当季确认 100%；初始年度收入 **189,608,000 元**，是合成值，不是 FY27 或真实 FY28 目标。
- 仅前三个校区的七、八年级春续暑续班率从 80% 开放至 80.1%；其余比例上下界固定。目标由端点正式内核求值生成，差额必须超过既有 10,000 元容差。

本用例不是 238 行自由入口结构搜索，也不是两类比例各开放 1 个百分点的宽边界测试。后者由 `tests/scale/test_wide_joint_budget.py` 独立覆盖，不能混淆两类证据。

## 验证链路

冻结合成来源 → 组合与比例版本 → 校区入口确认与范围 → 期初版本和幂等重放 → 计划新生锁定 → 952 行人数计算 → 资源财务/折扣确认 → Worker 重算 → 目标设置 → CP-SAT → 候选应用 → 新期初版本 → 重算 → 撤销恢复旧期初 → 重新应用 → 负责人正式确认 → 隔离发布。

同时校验：跨部门读取返回 404；比例版本变化后旧期初绑定失效，返回 `OPENING_BASIS_STALE`；发布返回的修订与预算正式指针一致，正式版本仍包含 952 行收入。

首次尝试中，极小入口人次在跨季取整后出现零人数，系统正确要求计划新生；入口范围排除后缺少校区覆盖也被正常阻断。最终用例通过正式输入 API 补齐，不绕过校验、不直接写结果或正式指针。

## 复现与证据

用例：`tests/integration/test_opening_api.py::test_fy28_opening_and_headcount_api[4-True]`。

仅在隔离数据库执行：

```sh
BUDGET_DATABASE_URL=postgresql+asyncpg://budget:budget@127.0.0.1:54329/budget_acceptance_20260905_real \
BUDGET_RUN_DB_TESTS=1 .venv/bin/pytest tests/integration/test_opening_api.py -q \
  --junitxml=output/scale-api-238-tests.xml --durations=3
```

完整集成回归记录为 `output/scale-api-238-integration-tests.xml`。本轮修改范围是合成验收用例，没有修改正式计算、优化或发布规则，也未新增期初维护页面。

结果：20 项完整集成回归全部通过，无失败、错误或跳过。增加正式发布指针及收入行数断言后，三种金额/规模用例再次全部通过；238 明细用例为 23.49 秒。Ruff、格式检查与 mypy 通过。本轮未重跑未修改的求解器规模测试或前端构建。
