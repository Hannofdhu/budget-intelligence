# FY28 预测基础预算 MVP

2026-10-07。范围：本机可试用的下一年预算拆解，非正式预算发布。

## 入口与操作

顶部固定为「查看预算 / 达成预测 / 下一年预算」。下一年预算地址 `/budget/next-year`。

从已确认、非试用、无数据阻断的 FY27 预测生成独立 FY28 草稿。默认先显示预算概览，五个同页任务分别为目标与范围、入口人数、招生参数、资源与财务、预算概览。修改后可先预览，再填写调整原因保存并重算。每次保存追加版本；不会覆盖来源或旧草稿。筛选后导出 XLSX，数值单元格保持数字格式。

## 默认衔接逻辑

- FY28 年度经营目标由用户手动指定，初稿的年度和赛道目标均留空。FY27 已确认预测收入只作为参考基数，不自动成为 FY28 目标。未填目标仍可计算、预览、保存人数和收入，但不展示目标差额或达成率。
- 填写年度目标后，可只保留年度目标，或由用户填写全部赛道目标；赛道目标合计必须等于年度目标。用户也可主动点击按当前预算收入比例分配赛道目标。清空年度目标时一并清空赛道目标，历史版本继续保留原值。
- 入口新生参考冻结来源的暑假业务新生，而不是退班分类中的“新生”；按校区再按组合分配，使用既有最大余数法，合计保持入口总值。
- 期初老生来自 FY27 春季预计总人次。复用既有七升八、八升九、九年级毕业退出及八年级地理/生物退出规则，再乘春续暑续班率。这里是预测参考人次，不是假造 BI 实际。
- 期初财务结转使用 FY27 春季预计转出金额，保持原财务维度，不跟人数升年级重复搬移。纯财务业务若存在非零跨年结转，拒绝静默丢弃；有结转金额的范围不能被直接关闭。
- 后续季度复用现有续班率、新生占比、人数取整、收入、班均检查、目标差额计算。零老生范围使用可编辑的计划新生。100% 新生占比不用于逆向推算。
- 学费、折扣、结转比例、班均优先继承同业务参数；升年级新增范围没有同年级参数时，先沿用同产品模板。没有适用续班率的新范围，用同赛道同年级有基数样本加权起步；只有原预测明确的规模保持业务沿用保持规模规则。这些是可编辑的 FY28 规划起点，不代表 FY27 原产品的实际续班率。
- 无适用比例和样本时先设为 0，并保存具体范围及起步说明；不声称已经获得真实历史参数。原来源及继承说明不可被修订替换。

## 复用与边界

计算直接调用 `packages/headcount`、`packages/revenue`、`packages/class_size`、`packages/target_closure`。跨年来源适配复用原期初转换函数，但采用独立的 `forecast-opening-students-v1` 来源规则标记，不能冒充正式发布要求的实际来源证明。

保存复用预测台账的文件锁、追加写入、幂等和哈希链机制，使用独立的 `output/next-year-ledger`，不新增重复的正式预算生命周期。接口为 `/api/v1/next-year-budgets/fy28/current|prepare|preview|revise`，沿用真实 FY27 档案的本机访问限制及现有角色验证。已有 FY28 合成预算 R150 在数据库中保持原状。

当前只提供独立规划草稿及重算，不提供确认或发布接口；`publication_available` 固定为 false。计算完整不等于发布检查通过，班均不足及收入差额保留可见。正式定版仍须接入原正式预算来源和既有门禁，不自动改变其规则。

## 验收范围

来源确认与指纹、只读/跨部门/非本机访问、幂等与过期父版本、固定来源不可替换、四季度参数完整覆盖、零入口、人次数学、升年级退出、结转保存、目标差额、预览不写入、数字格式导出、固定三模块导航和未保存离开保护。

不回写 FY27 Excel、档案提取、已确认预测台账或原 FY28 定版链。未向 GitHub、线上 BI 或生产环境发布真实预算数据。
