# 当前在读新生老生与总人次必须逐明细勾稽

自然滚动预测以当前在读人次作为季度终值起点前，系统必须在完整预算明细维度 `财季＋赛道＋产品＋年级＋科目＋校区` 校验：

`当前在读新生人次＋当前在读老生人次＝当前在读总人次`

该校验必须逐条明细精确成立，不设置人数容差，也不得用不同明细之间的正负差异或校区、部门汇总结果相互抵消。任一明细不相等时，系统必须展示对应维度、新生人次、老生人次、总人次和差异，并将该滚动版本标记为起点数据不一致。

起点数据不一致属于正式自然滚动预测的发布阻断条件。数据维护人员修复来源数据或字段映射并生成新快照后，系统重新执行校验；不得通过人工调整预计新增或预计退班绕过起点勾稽。
