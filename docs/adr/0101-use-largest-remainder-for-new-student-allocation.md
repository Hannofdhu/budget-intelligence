# 后续新增新生人次采用最大余数法取整

系统将校区预计后续新增新生人次按正向业务新生预算缺口权重分摊到 `赛道＋产品＋年级＋科目` 明细时，采用最大余数法生成整数人次：

1. 先计算每条明细的未取整分摊值；
2. 每条明细先向下取整；
3. 用校区预计总人次减去向下取整后的明细合计，得到待补人数；
4. 按小数余数从大到小依次为明细增加一人，直至待补人数归零。

小数余数相同时，必须按稳定的完整预算维度键排序决定补位顺序；同一参数版本、数据快照和输入值重复计算时必须产生完全相同的结果。系统必须保留未取整值、取整结果、余数和补位顺序，以便审计。

取整后的明细人次必须均为非负整数，且明细合计严格等于对应校区预计后续新增新生人次。人工修改后的结果继续遵守非负整数和校区合计一致校验。
