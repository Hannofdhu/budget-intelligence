# 已定版季度冻结实际禁止手动修改

已定版季度写入滚动预测版本的冻结实际人次和冻结实际收入均为只读。数据维护人员、部门预算负责人及其他角色都不得在预算系统内直接修改、覆盖或通过预测参数调整这些实际值。

冻结实际存在错误时，只能由数据维护人员修正来源数据或实际字段映射，完成必要的口径核验，并基于新的宽表 `dtdate` 分区和来源批次生成新的滚动预测版本。原版本及其错误值、字段映射和快照仍作为历史证据保留，不得追溯改写。

系统不得提供“调整定版实际”类输入入口，也不得允许通过恢复开放招生状态、叠加预计新增或预计退班等方式绕过只读限制。
