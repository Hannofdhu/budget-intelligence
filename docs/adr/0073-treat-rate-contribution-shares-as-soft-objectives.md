# 比例参数收入贡献份额作为软目标

平衡、留存侧和招生侧方案的 50/50、70/30、30/70 收入贡献比例是候选方案的优化目标，不是必须精确满足的硬约束。求解时首先确保智慧伴学、智慧空间和部门收入分别进入正负一万元容差，并满足参数边界、整数人次、班均及其他全部业务约束；然后在可行解中尽量接近对应贡献比例。

由于续班率和新生占比采用 0.01 个百分点步长、人数采用整数取整且参数受确认边界限制，实际贡献比例允许偏离目标。系统不另设贡献比例容差，也不得仅因无法精确命中贡献比例而判定预算不可行。

每个候选方案必须展示目标贡献比例、实际贡献金额与比例、偏离金额及偏离原因，使部门预算负责人能够区分步长取整、边界转移和其他约束造成的差异。
