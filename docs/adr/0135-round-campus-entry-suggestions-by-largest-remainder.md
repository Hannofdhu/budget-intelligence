# 校区入口建议值采用最大余数法取整

新校区、无可用历史校区的人工建议预留必须填写非负整数人次。系统从整数财年入口总值中扣除这些人工预留后，按 ADR-0134 计算每个有历史校区的建议理论小数人次；先取各理论值的整数部分，再将剩余人次依次分配给小数余数最大的校区。

小数余数相同时按稳定校区 ID 排序，不使用可能变化的校区名称。取整后的全部有历史校区建议值，加上无历史校区人工建议预留，必须严格等于财年入口总值；相同输入必须得到相同整数结果。

全体校区均无历史时不执行最大余数分配，全部人工建议值本身必须是非负整数且合计严格等于财年入口总值。系统同时保留有历史校区的建议理论值、整数建议值和尾差归属，用于解释和复算。
