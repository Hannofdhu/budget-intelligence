# 退班率样本门槛采用部门级单一配置

退班率最小样本门槛采用智慧学习部部门级单一配置，同时适用于退班分类新生、退班分类老生，以及去年同期过程退班率分母和去年最终退班率分母。默认值为 30 人次。

系统不得按校区、赛道、产品、年级、科目、退班分类或过程／最终阶段分别设置不同门槛，避免同一滚动版本内使用不同的历史可信度标准。

只有数据维护人员可以修改退班率最小样本门槛。修改必须生成新的配置版本，并触发所有未定版财季的退班率回退、预计剩余退班人次、季度终值和收入重新计算；既有退班预测最终确认立即失效，部门预算负责人重新确认后才能发布。

配置版本必须保留修改前后值、修改人、修改时间和原因，并随滚动版本冻结；不得追溯改写已经生成的滚动版本。
