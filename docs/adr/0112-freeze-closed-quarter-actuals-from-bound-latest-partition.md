# 定版季度实际取自版本绑定的宽表最新分区

财季被指定为“已定版”时，冻结实际统一取自该滚动预测版本生成时“智慧学习部指标汇总宽表”的最新 `dtdate` 分区。版本必须保存数据集名称与标识、`dtdate`、来源批次和生成时间。

数据维护人员必须登记已定版季度所使用的实际人次字段、实际收入字段及必要计算公式。字段映射未完成、口径无法核验或所选分区缺少定版数据时，该财季不能进入可发布的已定版状态。

冻结实际一经写入滚动预测版本，后续更晚的宽表分区不得自动改变该版本的人次、收入或计算结果。需要采用更新分区或修正字段映射时，必须生成新的滚动预测版本；原版本及其冻结实际永久保留。
