# 退班预测按校区和新老生类型汇总取整后下分

预计剩余退班人次必须输出整数，但不得在预算明细层逐行独立四舍五入。系统先保留每条明细的未取整预计值，再在同一财季、同一校区内分别汇总新生和老生的预计剩余退班人次。

每个 `财季＋校区＋新老生类型` 合计使用普通四舍五入生成整数，尾数恰好为 `.5` 时向上进位，不使用银行家舍入。随后以各明细未取整预计值为依据，采用最大余数法将该整数合计分配到 `赛道＋产品＋年级＋科目` 明细；余数相同时按稳定的完整预算维度键排序。

取整后的每条明细预计剩余退班人次必须为非负整数，不得超过该明细当前仍可退班的人数。触及明细上限后，未分配人数继续按剩余明细的余数顺序和可用空间分配。若校区类型合计超过全部明细可退班人数，系统必须将结果限制在可退班人数内并报告数据或参数不可行，不得突破人数上限。

系统必须保留明细未取整值、校区类型未取整合计、四舍五入后合计、明细取整结果、余数和补位顺序，以支持复核和重算。
