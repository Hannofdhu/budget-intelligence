# 滚动补缺方案允许带剩余缺口发布

滚动补缺方案发布表示部门预算负责人确认采取方案中列明的经营措施，不代表年度预算缺口已经完全消除。即使在已确认参数边界和其他业务约束内仍存在剩余缺口，方案仍可正式发布。

每个补缺方案必须展示其绑定自然滚动预测的原始缺口、预计补缺金额、补缺率、调整后季度及全年收入和剩余缺口。剩余缺口绝对值不超过一万元时显示“无显著缺口”；超过一万元时明确显示“仍有缺口”，不得使用预算达成或闭合表述。

营收缺口本身不阻止补缺方案发布，但数据不完整、未映射实际、参数越界、修改冻结实际、角色未确认及其他治理校验失败仍然属于发布阻断项。系统不得将经营结果不足与数据或治理异常混为一谈。
