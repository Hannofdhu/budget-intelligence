# 零值空维度行自动排除，非零时阻断预测

退班预测正式输入要求 `赛道＋产品＋年级＋科目＋校区` 五个业务维度全部具有具体值。任一必填业务维度缺失的源数据行不得作为预算明细，也不得参与任何退班率回退层级的分子、分母或当前基数汇总。

当维度不完整行的当前新生、老生退班分类在班基数，以及新生、老生同期过程与最终退班分子、分母等全部退班预测相关数值均为零时，系统自动从退班预测输入中排除，并记录快照分区、排除行数、空缺维度和零值校验结果；这种纯零占位行不阻止正式自然滚动预测发布，也不要求人工逐行处理。

只要维度不完整行的任一退班预测相关当前基数、历史分子或历史分母不为零，系统必须阻断正式自然滚动预测，要求数据维护人员修正来源维度或建立完整映射。系统不得把非零记录并入部门层、平均分配到完整维度、默认补写维度值或通过上层汇总抵消。

维度不完整的纯零行即使形成重复空键，也按本规则排除并审计，不参与预算粒度唯一性校验；完整业务键之间的重复仍执行既定唯一性硬校验。
