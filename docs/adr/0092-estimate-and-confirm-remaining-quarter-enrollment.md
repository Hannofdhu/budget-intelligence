# 参考去年同进度估算并确认季度剩余新增

自然滚动预测对尚未结束的季度计算终值时，不得将预计后续新增人次默认为零。系统使用去年同季度从相同预测进度到季度最终的新增发展量生成参考值：

`去年剩余新增人次＝MAX(0，去年最终累计新增人次－去年同期过程累计新增人次)`

系统生成的预计后续新增人次只是业务参考值，必须与其历史过程值、最终值、预测基准日和来源快照一并展示，由业务方确认后才能成为当前滚动预测参数。业务方可以基于当年招生节奏、校区资源、新产品和其他已知经营变化修改参考值，修改后必须保留系统建议值、确认值、确认人、确认时间和修改原因。

缺少去年同期过程数据、历史口径无法匹配或新产品没有可比历史时，系统不得自动填零或编造参考值，必须转为人工填写并确认。季度终值继续按 `当前在读人次＋已确认预计后续新增人次－预计剩余退班人次` 计算。
