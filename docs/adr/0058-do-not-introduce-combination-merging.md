# 不引入预算组合合并方案

为降低概念复杂度和使用难度，系统不提供预算组合合并、合班组或通过合并人数满足班均的处理方式。预算组合继续保持独立的人数、收入、班均校验和实际映射，不建立额外的组合关系。

对于计划总人次低于班均的已启用预算组合，数据维护人员可以准备调整方案，部门预算负责人只能在“增加招生目标”和“关闭预算组合”中确认最终处理方式。异常未消除前阻止正式预算发布，不允许忽略异常或带异常发布；处理动作及其原因、操作人、时间和预算版本必须保留审计记录。

本决策替代 ADR-0057 以及 ADR-0027 原有表述中包含合并方案的处理规则。
