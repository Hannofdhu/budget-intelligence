# 续班率与新生占比统一采用最终考核口径

预算拆解中的历史参考值、系统初始值、调平参数、业务目标值和发布校验统一采用“智慧学习部学员花名册”的最终考核口径，不再并行维护另一套预算专用续班率或新生占比。

续班率保持为：

`(SUM(续班人次) - SUM(专项班续班人次)) / SUM(原班人次)`

新生占比统一调整为：

`SUM(业务新生人次) / SUM(招生人次(三分之二出勤口径))`

“招生人次(三分之二出勤口径)”与“业务新生人次”共享专项、月卡、正结转、会员卡及班级结课状态和三分之二出勤等主体条件；它不限制新老生身份，用作总人次分母。两项比例均须先按所需维度汇总分子和分母后相除，不得平均明细比例；分母为零时按无历史数据处理并进入既定回退流程。不得使用“目标-续班率”“业务目标-续班率”“续班人次-集团口径”等目标或集团字段替代实际口径。
