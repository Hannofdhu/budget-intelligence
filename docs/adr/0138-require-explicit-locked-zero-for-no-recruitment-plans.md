# 零老生行必须显式填写并锁定计划新生人次

老生理论人次为零且没有入口分配或其他已确认新生绝对量的完整季节预算明细，必须显式填写并锁定计划新生人次；即使业务计划不招生，也必须明确填写并锁定 0 人。

计划新生人次空值表示“尚未处理”，不得自动解释为 0，不得参与正式方案确认，并阻止年度预算基线发布。填写并锁定 0 人表示业务方已明确确认该季节明细不计划招收新生；该行新生占比结果为不适用，继续参与四季全零组合、班均及其他既定发布校验。

系统必须在正式方案确认摘要和发布检查中分别列出未处理空值与已锁定零值，不能仅凭页面显示的 0 混淆两种状态。
