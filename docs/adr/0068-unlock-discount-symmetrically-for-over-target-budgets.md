# 超目标时按对称条件解锁折扣率调平

预算收入超目标时，只有在固定财年入口总值内已不存在符合入口硬边界的进一步降额分配方案、续班率和新生占比均已达到各自确认下限，并且任一赛道或部门收入仍高于目标上界时，才具备折扣率调平解锁条件。

数据维护人员可以发起解锁，部门预算负责人必须针对当前草稿重新确认。解锁后系统只能在既定部门、赛道、年度和季节综合折扣率约束内生成明细折扣率候选方案，不得借此修改综合折扣目标。

在折扣率边界和综合折扣约束内仍无法消除超额时，系统必须报告不可行超额并阻止正式发布，不得跨赛道抵消、扩大目标容差或突破参数边界。任何上游参数或方案变化都会使缺口证明与解锁状态失效。
