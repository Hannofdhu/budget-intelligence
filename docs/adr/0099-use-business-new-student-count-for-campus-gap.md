# 校区新生预算缺口统一使用业务新生人次口径

自然滚动预测计算校区预计后续新增新生人次时，校区新生人次预算值和当前累计完成值必须统一采用“业务新生人次”口径：

`校区预计后续新增新生人次＝MAX(0，该财季该校区业务新生人次预算值－该财季该校区当前累计业务新生人次)`

预算值和当前完成值必须属于同一财季、同一校区及同一业务新生定义。系统不得将入口人次预算、招生人次、招生人次（三分之二出勤口径）、普通新生人次或其他近似字段与业务新生人次混合计算。

数据维护人员必须在参数版本中保留预算值字段、当前完成值字段、数据集、`dtdate` 和来源批次。任一侧口径无法确认一致时，不得生成校区预计后续新增默认值，必须显示口径异常并阻断正式自然滚动预测。
