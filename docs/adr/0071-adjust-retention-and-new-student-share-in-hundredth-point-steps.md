# 续班率与新生占比按零点零一个百分点步长调平

续班率和新生占比自动调平的最小步长固定为 0.01 个百分点，参数按百分点两位小数保存、计算和展示。数据维护人员可以直接输入符合该精度的目标值，不要求通过逐步点击完成调整。

该步长与明细折扣率已确定的 0.1 个百分点步长相互独立。系统在执行等百分点水位法、完整人数推演和整数人次取整后，必须使用最终参数精度重新校验智慧伴学、智慧空间和部门目标。

如果在 0.01 个百分点步长、整数人次以及其他既定约束下仍无法使三个目标分别进入正负一万元容差，系统必须报告不可行，不得使用隐藏小数位、扩大容差或只依赖页面四舍五入形成假闭合。
