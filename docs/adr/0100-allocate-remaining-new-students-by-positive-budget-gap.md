# 按明细正向业务新生预算缺口分摊后续新增

校区预计后续新增新生人次确定后，系统按该校区各 `赛道＋产品＋年级＋科目` 明细尚未完成的业务新生人次预算缺口进行自动分摊：

`明细正向缺口＝MAX(0，明细业务新生人次预算值－明细当前累计业务新生人次)`

`明细分摊权重＝明细正向缺口÷校区全部明细正向缺口合计`

`明细预计后续新增新生人次＝校区预计后续新增新生人次×明细分摊权重`

当前累计业务新生人次已经达到或超过明细预算值的明细，默认分摊权重为零。当前业务新生人次为零但存在正向业务新生预算的明细仍可获得分摊；因此不得再以今年累计业务新生人次占比作为默认权重。

分摊后的明细人次必须为整数，且明细合计严格等于校区预计后续新增新生人次。校区全部明细正向缺口合计为零、明细缺少业务新生人次预算，或新产品尚未建立预算明细时，必须转为人工分配并保留原因，不得静默平均分配。

数据维护人员和部门预算负责人仍可按既定权限调整校区预计值或明细分布，最终结果由部门预算负责人确认。本决策仅替代 ADR-0094 中按今年累计业务新生人次明细占比分摊的规则；ADR-0094 的校区预计总量算法继续有效。
