# 季度终值使用退班分类在班基数

“智慧学习部指标汇总宽表”中的业务新老生拆分与退班新老生拆分并不等价。最新已核验快照中，`招生人次` 与 `退班基数(在班基数)` 逐明细相等，且后者可逐明细拆为 `新生退班基数(在班基数)` 与 `老生退班基数(在班基数)`；因此，自然滚动预测使用退班分类在班基数作为新老生退班的起点，不使用业务新生字段代替。

`退班分类新生季度终值人次＝新生退班基数(在班基数)＋预计后续新增业务新生人次－预计剩余新生退班人次`

`退班分类老生季度终值人次＝老生退班基数(在班基数)－预计剩余老生退班人次`

`季度终值总人次＝招生人次＋预计后续新增业务新生人次－预计剩余新生退班人次－预计剩余老生退班人次`

系统必须在完整预算明细维度校验 `新生退班基数(在班基数)＋老生退班基数(在班基数)＝退班基数(在班基数)＝招生人次`，不设置人数容差，也不得以上层汇总抵消明细差异。任一等式不成立时，阻断正式自然滚动预测。

宽表 `新生人次`（来源为 `业务新生人次`）仅用于校区业务新生预算缺口和预计后续新增业务新生人次，不作为退班预测的当前新生起点。页面和导出必须将终值拆分明确标注为“退班分类新生”和“退班分类老生”，不得表述为业务新生、业务老生构成。

本决定替代 ADR-0108 和 ADR-0109 对当前在读新老生起点及其勾稽关系的定义。
