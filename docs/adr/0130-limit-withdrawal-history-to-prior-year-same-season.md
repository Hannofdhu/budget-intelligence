# 退班预测历史窗口仅使用上一财年同季节

自然滚动预测的退班率历史窗口固定为上一财年同季节。例如，预测 FY27 秋季时，只使用 FY26 秋季对应的同期过程退班字段和最终退班字段。

ADR-0123 的逐级回退只改变校区、科目、年级、产品和赛道等业务维度，不改变历史年度与季节。系统不得在上一财年同季节数据不可用时继续搜索 FY25 或更早年度，也不得跨暑假、秋季、寒假、春季借用历史率。

上一财年同季节在部门、退班分类层级仍不满足字段完整性或最小样本门槛时，进入“无可用退班历史”流程，直接人工填写预计剩余退班人次。更早年度数据可以用于人工判断的辅助展示，但不能作为系统自动退班率回退来源。

系统必须随滚动版本记录当前预测季节、对应的上一财年同季节、数据快照和来源批次，保证历史窗口可复算且不受后续数据更新影响。
