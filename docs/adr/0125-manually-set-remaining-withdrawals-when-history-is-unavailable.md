# 无可用退班历史时直接填写预计剩余退班人次

自然滚动预测按 ADR-0123 逐级回退后，如果部门同季节、同退班分类层级仍不能满足 ADR-0124 的字段完整性和最小样本门槛，系统将该范围标记为“无可用退班历史”。

系统不得补造、覆盖或要求人工填写去年同期过程退班率、去年最终退班率或历史剩余退班率。数据维护人员或部门预算负责人应直接按 `财季＋校区＋退班分类` 填写预计剩余退班人次，并保留填写前状态、填写值、填写人、时间和原因。

无可用退班历史且预计剩余退班人次尚未填写时，正式自然滚动预测不得发布；不得将缺失值静默按零处理。填写后的结果仍须遵守预计剩余退班人次不得超过对应可退班人数等既定硬约束，并由部门预算负责人完成最终确认后才能进入正式版本。

本决策不改变历史退班率只读原则；人工判断作用于预测结果，而不是改写历史证据。
