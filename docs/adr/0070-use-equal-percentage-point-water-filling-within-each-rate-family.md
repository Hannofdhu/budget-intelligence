# 同类比例参数内部采用等百分点水位法

续班率和新生占比在各自参数集合内部均采用“等百分点推进、触及确认边界后退出”的水位法，不采用按当前值等比例推进。对同一赛道内所有符合条件的同类参数，系统从当前确认值开始同时增加或减少相同百分点，并通过完整人数与收入模型确定完成该类收入贡献所需的共同变化量。

某条参数达到确认上限或下限后立即退出后续推进，其余参数继续增加或减少相同的新增百分点，直至完成该类参数应承担的收入贡献，或者所有参数都达到对应方向的确认边界。最小样本不足、没有确认边界或被人工锁定的参数不参与自动调整。

系统不得因为某条参数当前值更高、人工边界更宽、学费更高或单个百分点边际收入更大，就优先将压力集中到该明细。按当前值等比例推进可以用于分析对照，但不得生成或影响正式自动调平方案。
