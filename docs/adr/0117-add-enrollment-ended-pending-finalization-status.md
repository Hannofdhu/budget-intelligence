# 增加招生结束待定版财季状态

财季生命周期扩展为四个必选状态：

- `未来未开始`：尚无本财季实际业务进度，按父版本有效参数推演；
- `开放招生`：仍在招生，预测后续新增和剩余退班，并按季末终值人次重算全季度收入；
- `招生结束待定版`：招生已经结束但财季尚未定版，预计后续新增新生人次默认为零，继续预测预计剩余退班，并按季末终值人次重算全季度收入；
- `已定版`：使用冻结实际人次和收入，停止使用开放期预测参数。

只有数据维护人员可以修改财季状态。状态变化必须记录前后状态、修改人、时间、原因和来源批次，并生成新的滚动预测版本；原版本不得覆盖重算。

财季从“开放招生”进入“招生结束待定版”时，新版本中的系统预计后续新增新生人次默认重算为零；预计剩余退班继续按已核验规则计算。财季进入“已定版”后，两类预测参数均退出计算，只保留审计历史。

本决策替代 ADR-0111 的三态枚举，继续保留其中由数据维护人员维护状态、状态变化生成新版本和原版本永久保留的治理原则。
