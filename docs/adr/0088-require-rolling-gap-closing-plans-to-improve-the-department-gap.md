# 滚动补缺方案必须改善部门年度缺口

滚动补缺方案相对其绑定自然滚动预测，调整后的部门年度缺口必须有所减少，才能以“补缺方案”名义正式发布。部门缺口没有改善的结果只能保存为试算方案，不得通过更换名称或只展示局部指标绕过。

系统必须分别展示部门及智慧伴学、智慧空间的调整前缺口、预计改善或恶化金额和调整后缺口。如果任一赛道缺口扩大，方案必须填写具体原因，并由部门预算负责人在发布时针对该赛道恶化执行显式确认；部门合计改善不得掩盖赛道层面的恶化。

该规则不要求完全消除部门或赛道缺口，剩余缺口仍按照既定规则如实展示。
