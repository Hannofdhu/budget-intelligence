# 正式参数必须使用对齐的花名册与宽表刷新链路

如果“智慧学习部学员花名册”已经刷新，而“智慧学习部指标汇总宽表”的最新 `dtdate` 分区尚未完成对应的下游刷新，系统不得混用较新的花名册与较旧的宽表快照生成正式参数。

正式参数冻结前，必须确认花名册 ETL 成功、指标宽表完成对应下游刷新，并将宽表最新 `dtdate`、宽表任务批次和花名册任务批次关联为同一数据截止链路。下游快照尚未跟上时只能生成标记为“等待宽表快照”的参数草稿；刷新完成后必须重新对账，通过后才能冻结。系统不得通过手工修改 `dtdate` 或选择次新分区绕过该要求。
