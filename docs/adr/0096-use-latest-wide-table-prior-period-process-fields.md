# 使用宽表最新分区的同期过程字段对齐退班进度

自然滚动预测计算去年相同进度退班率时，直接使用“智慧学习部指标汇总宽表”最新 `dtdate` 分区中已经生成的同期过程字段，不要求数据维护人员另外保存或补建去年的历史快照。

每个滚动预测版本必须保存本次使用的 `dtdate`、数据集标识、来源批次和生成时间，以保证同期过程值可追溯。系统不得在版本生成后改用更新分区重算同一版本；需要更新数据时必须生成新的滚动预测版本。

同期过程字段的可用性不代表指标口径自动成立。正式启用退班预测前，仍必须确认新生和老生各自的同期过程退班分子、同期过程分母、最终退班分子及最终分母属于同一统计口径。老生同期过程退班分子还必须逐预算明细满足 ADR-0122 的新老生补集勾稽。字段缺失、分母为零或口径不能匹配时，进入既定回退流程或人工确认，不得用当季新招新生字段或其他近似字段静默替代。
