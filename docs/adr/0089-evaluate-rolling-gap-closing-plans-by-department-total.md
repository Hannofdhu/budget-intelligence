# 滚动补缺方案以部门合计为唯一成立标准

是否存在需要补缺的营收缺口、补缺方案是否有效、补缺率和剩余缺口，统一以智慧学习部部门合计判断。滚动补缺方案相对其绑定自然滚动预测，调整后的部门年度缺口必须有所减少，才能以“补缺方案”名义正式发布。

赛道缺口、改善或恶化金额继续拆分展示并用于原因分析，但不构成独立补缺条件或发布门槛。部门合计已经处于“无显著缺口”状态时，即使某个赛道仍有缺口，也不要求且不得仅以赛道缺口发布正式滚动补缺方案；相关调整只能保存为试算方案。

部门合计未改善的方案同样只能保存为试算，不得以正式补缺方案发布。本决策替代 ADR-0088 中将赛道恶化设为独立显式确认条件的规则。
