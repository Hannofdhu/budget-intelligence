# 计划新生人次作为可锁定的人工人数输入管理

计划新生人次由数据维护人员和部门预算负责人按“季节＋赛道＋产品＋入口属性＋年级＋科目＋校区”完整预算明细直接修改、锁定或解锁。每次填写或修改必须记录具体人数和原因；两类角色均可独立完成操作，不增加单独审批环节。

计划新生人次及其锁定状态必须纳入部门预算负责人的正式方案确认。修改或解锁后，受影响的下游人数、收入、班均、候选调平方案和原正式方案确认全部失效并重新计算，旧值和旧锁定记录继续保留用于审计。

计划新生人次是解决零老生行绝对新生量的人工计划输入，不作为入口分配、续班率、新生占比或折扣率之外的新自动调平杠杆。调平引擎不得自动生成、增加、减少、解锁或覆盖计划新生人次。
