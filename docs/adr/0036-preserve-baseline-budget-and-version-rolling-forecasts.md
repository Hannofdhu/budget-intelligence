# 保留原预算并以独立版本进行滚动预测

已经批准的年度预算版本永久保留，不得被后续实际数据或滚动预测覆盖。每次滚动更新生成独立的滚动预测版本，并记录预测基准日、参数版本和数据快照。

已经达到数据成熟条件的季节使用实际人次和实际收入并在该滚动版本中冻结；尚未成熟的当前季节只能标记为过程数据，不得作为最终实际。未来季节以上一季最新有效人次为起点，按当前有效参数继续推演。已结束季节的预算缺口不得回写修改，只能形成需要由未来季节承担的剩余目标。

每个滚动预测版本必须并列展示原年度预算、当前实际或预测以及相对年度预算基线的差异原因。上一滚动预测版本继续保留用于审计，但按照 ADR-0083 不在滚动预测页面展示对比。
