# 退班口径核验只能由数据维护人员解除

“口径待核验”状态只能由数据维护人员解除。解除前，数据维护人员必须分别为新生和老生登记去年同期过程退班分子、同期过程退班分母、去年最终退班分子和最终退班分母的具体字段映射及完整计算公式。

每次核验记录还必须保存数据集名称与标识、验证使用的 `dtdate`、核验人、核验时间和必要说明。老生核验记录必须另存新老生过程退班分子逐预算明细补集勾稽的通过结果。四项字段映射、公式、数据集、验证分区或补集勾稽任一缺失时，系统不得将状态改为已核验。

部门预算负责人可以查看核验证据，但不能代替数据维护人员解除口径阻断。字段映射或公式后续发生变化时，必须形成新的核验记录并只作用于新生成的滚动预测版本，不得追溯改写已固定版本。
