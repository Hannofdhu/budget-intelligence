# 调整退班明细时同步重算校区类型合计

预计剩余退班人次允许在 `赛道＋产品＋年级＋科目` 单条明细上直接调整。任意明细发生变化后，对应的 `财季＋校区＋新老生类型` 合计必须立即按全部明细重新求和，不能要求明细继续保持调整前的校区类型合计。

当用户直接修改 `财季＋校区＋新老生类型` 合计时，系统才以新合计为输入，按照既定预测权重和最大余数法重新分配到明细。当用户修改单条明细时，明细是本次操作的输入，校区类型合计是派生结果；系统不得为了恢复原合计而自动反向修改其他明细。

明细和重算后的校区类型合计均须继续满足非负整数、不得超过可退班人数等既定约束，并记录调整前后明细值、合计变化、调整人、时间和原因。调整完成后仍须由部门预算负责人最终确认。
