# 预算组合变化按实际依赖范围使确认和计算失效

预算组合范围发生变化后，系统必须按实际影响范围撤销旧确认或旧计算结果，并明确展示失效原因及需要重新处理的步骤，不得静默沿用不再适用的结果。

新增或关闭整个校区会改变校区入口分配范围，因此整套校区入口确认失效，必须重新分配并由部门预算负责人再次确认。只调整现有校区内的产品、入口属性、年级或科目组合时，校区入口总值及其确认继续有效，但该校区的明细入口下拆、人数推演和后续收入测算失效并重新计算。

重新计算后的结果仍须通过原有业务确认、目标闭合、班均、折扣率和发布校验，不能因为上游确认被保留而跳过下游校验。
