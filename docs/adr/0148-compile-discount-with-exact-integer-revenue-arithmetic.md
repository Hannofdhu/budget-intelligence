# 折扣阶段采用精确整数收入模型而非折扣笛卡尔枚举

折扣解锁后，若对每条明细的 0.1 个百分点离散值做笛卡尔枚举，搜索空间会随明细数指数增长；若用线性近似代替，又会丢失六位小数四舍五入、含税转换和跨季结转的正式口径。

第三阶段直接在 CP-SAT 中使用整数微元、乘法等式和带半入的除法等式，表达人数×折后单价、不含税收入、当季确认和跨季结转。含税转换系数先约分为最小有理数，避免无意义放大中间量。明细折扣严格位于 1,000 ppm 网格，且年度与季度、部门与赛道的综合折扣在四个反事实人数口径下都作为硬约束。

所有乘法、除法和线性中间量在求解前做 64 位范围证明；不能证明时返回“计算未完成”，不缩小业务范围。求解器返回最优解后，全部决策交给正式计算内核复算；只有完整硬约束模型证明无解时才返回“业务不可行”。
