# 招生结束待定版允许例外调整后续新增

财季处于“招生结束待定版”状态时，系统预计后续新增新生人次默认为零，但数据维护人员和部门预算负责人可以针对补录、晚报名或其他已知例外，将校区预计后续新增新生人次人工调整为大于零。

人工调整继续使用既定的明细分摊、非负整数、校区与明细合计一致和版本留痕规则。系统必须保留默认零值、调整后值、调整人、调整时间和具体原因，不得将例外调整改写为系统默认预测。

调整行为不等于最终确认。只有部门预算负责人能够最终确认例外后续新增；确认后再次修改时原确认自动失效。未经确认的例外值只能保存在滚动草稿中，不得用于发布正式自然滚动预测。
