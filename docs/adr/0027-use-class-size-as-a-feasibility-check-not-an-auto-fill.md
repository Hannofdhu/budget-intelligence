# 班均作为开班可行性约束而非自动补人公式

预算系统先按入口人次、续班率和新生占比计算计划人次，不得像原 Excel 一样在预算行低于班均时直接增加新生人次。班均仅用于校验已启用预算组合的开班可行性，并作为锁定的资源参数，不参与年度总结转自动调平。

当计划总人次低于最低成班人数时，系统将该组合标记为不可成班并展示人数缺口，只允许在既定目标与参数边界内增加招生目标或关闭组合，不引入组合合并方案。任何会改变计划人次或预算组合状态的方案都必须由部门预算负责人确认后生效，并形成可审计的版本差异；系统不得静默补人。

## 2026-10-23 口径补充

用户确认同一“班均”同时用于开班门槛检查和预算班量估算，替代原文“仅用于校验”的范围限制，不再单设“计划班额”。每条季度明细的预算班量按“整数计划总人次÷班均”向上取整，零人次为零班；原有不自动补人、不参与收入调平、保留历史版本原结果及显式保存的边界不变。
