# 退班率回退必须满足最小样本门槛

自然滚动预测在 ADR-0123 的每一个退班率回退层级上，都必须同时检查去年同期过程退班率分母和去年最终退班率分母。两项分母分别达到可配置的最小样本门槛时，该层级才可用于计算；默认门槛均为 30 人次。

同期过程分子或最终分子为零属于有效历史数据，只要对应字段存在、分母达到门槛，就不得仅因分子为零继续回退。任一所需字段缺失，或同期过程分母、最终分母中的任一项不足门槛时，该明细的两项退班率必须一起进入下一回退层级，不得只回退其中一项，也不得跨层拼接。

系统必须随滚动版本保存实际采用的门槛、两项样本分母、采用的回退层级和回退原因。门槛调整属于配置变更，只影响基于新配置生成的新滚动版本，不追溯改写既有版本。
