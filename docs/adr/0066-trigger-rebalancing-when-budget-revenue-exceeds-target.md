# 预算收入超出目标后重新触发调平

任何上游参数、入口分配或方案变化后，系统必须分别重新校验智慧伴学、智慧空间和部门合计预算收入。各目标继续使用正负一万元绝对误差；任一赛道或部门收入超过其目标加一万元时，草稿进入“超目标待调平”状态。赛道之间不得以一方超额抵消另一方缺口。

进入该状态后，草稿仍可保存、试算和比较，但原候选结果、正式方案确认和折扣率调平解锁状态全部失效，并阻止正式发布。系统必须分别展示部门和各赛道的超目标差额，不得自动削减入口人次、续班率、新生占比或折扣率。

重新降额调平仍按既定杠杆顺序执行：先在固定财年入口总值内调整入口分配结构，再将续班率与新生占比作为并列杠杆调整，折扣率最后且必须重新显式解锁。财年入口总值不得因超目标而直接减少。全部已确认边界内仍无法回到目标容差时，系统报告不可行，不得跨赛道抵消、突破边界或扩大容差。
