# 滚动预测默认不调平并先揭示自然营收缺口

生成滚动预测时，系统默认不得为了闭合年度或季度预算目标自动调整入口分配、续班率、新生占比或折扣率。成熟期间使用已冻结实际；未成熟期间沿用父版本原有的续班率、新生占比和其他有效参数进行推演。首个滚动预测的父版本为年度预算基线，后续滚动预测沿用上一正式滚动版本的有效参数。

系统据此生成自然滚动预测，分别展示各季度、各赛道和部门的预计收入、年度预计收入，以及相对年度预算基线对应预算值的缺口或超额。自然滚动预测的首要作用是让业务方看清“已冻结实际＋剩余期间原有经营参数”将产生的真实结果，生成过程不得自动抹平差异。

只有在自然滚动预测及其缺口已经生成并保留后，业务方才能另行制定补缺方案。补缺方案不得覆盖自然滚动预测，也不得追溯修改冻结实际；它必须作为独立草稿展示所调整参数、预计补缺金额、剩余缺口和业务压力。
