# 自动退班率回退统一进入标准最终确认

由 ADR-0123 自动生成的退班率回退结果不要求部门预算负责人逐条单独确认，也不新增独立审批流程。所有自动预测结果统一进入既有的退班预测最终确认，由部门预算负责人按滚动版本执行正式确认。

系统必须为每条预测明细展示并随版本保存：实际采用的回退层级、去年同期过程分母、去年最终分母、去年同期过程退班率、去年最终退班率、历史剩余退班率和最终预计剩余退班人次。展示值必须能够追溯到该层级汇总后的原始分子、分母及数据快照。

采用“去产品但保留赛道”或“去赛道使用部门同季节值”的结果统一标记为“宽范围回退”。该标记用于提示部门预算负责人重点关注，但只要字段口径、样本门槛、人数上限和其他既定硬约束均通过，就不单独阻止确认或正式发布。

人工修改预计剩余退班人次时，仍执行既有的留痕、确认失效和重新确认规则；“宽范围回退”提示不得因人工修改而从审计记录中删除。
