# 允许修改比例参数并在同一操作中锁定

数据维护人员或部门预算负责人锁定续班率、新生占比时，可以直接锁定当前确认值，也可以输入新的目标值并立即锁定。修改并锁定必须作为一个原子操作保存，不得产生“参数值已经改变但锁定尚未生效”的中间正式状态。

新锁定值必须符合 0.01 个百分点精度，处于该完整参数键已确认的上下限内，并填写修改原因。操作记录必须同时保留修改前值、修改后值、锁定状态、原因、操作人、时间、参数版本及当时角色快照。

保存成功后，系统立即使依赖旧值或旧锁定状态的候选方案、正式方案确认和折扣率调平解锁失效，并重新计算人数、收入、班均、目标闭合及其他受影响校验。
