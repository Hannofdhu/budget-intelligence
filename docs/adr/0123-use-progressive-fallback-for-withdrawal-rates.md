# 退班率采用逐级自动回退

为降低退班预测因明细无历史数据而产生的人工维护量，新生和老生的去年同期过程退班率、去年最终退班率采用以下固定回退顺序：

1. `季节财年＋赛道＋产品＋年级＋科目＋校区＋退班分类`；
2. 去校区：`季节财年＋赛道＋产品＋年级＋科目＋退班分类`；
3. 去科目：`季节财年＋赛道＋产品＋年级＋退班分类`；
4. 去年级：`季节财年＋赛道＋产品＋退班分类`；
5. 去产品但保留赛道：`季节财年＋赛道＋退班分类`；
6. 去赛道，使用部门同季节同退班分类：`季节财年＋退班分类`；
7. 部门层仍不可用时，标记“无可用退班历史”，并按 ADR-0125 直接人工填写预计剩余退班人次。

`季节财年`和`退班分类（新生／老生）`是不可回退边界，不得跨季节或混合新老生。每一级都必须先分别汇总分子和分母，再计算比率，不得平均明细率。

同一条预算明细的去年同期过程退班率与去年最终退班率必须取自同一个可用回退层级；不得分别从不同层级取数后计算剩余退班率。系统必须记录并展示实际采用的回退层级。只有当前层级所需字段和分母均满足适用条件时，才能停止回退；否则继续进入下一层级。

本规则只适用于自然滚动预测的退班率，不改变续班率和新生占比在 ADR-0021、ADR-0022 中既定的历史值回退范围，也不允许人工改写历史退班率。
