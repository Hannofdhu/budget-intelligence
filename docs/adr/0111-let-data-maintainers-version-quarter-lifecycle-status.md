# 财季状态由数据维护人员指定并随新滚动版本生效

每个财季必须由数据维护人员明确指定一种生命周期状态：

- `未来未开始`：尚无本财季实际业务进度，按父版本有效参数推演；
- `开放招生`：尚未定版且仍在招生，按预测季末终值人次重算全季度收入；
- `已定版`：使用冻结实际人次和收入，不再接受预测参数重算。

只有数据维护人员可以修改财季状态。每次修改必须记录修改前状态、修改后状态、修改人、修改时间、原因和依据的数据批次。

财季状态变化后必须基于新状态生成新的滚动预测版本，并固定新的数据快照、状态和计算结果。原滚动版本及其财季状态、参数、确认记录和结果永久保留，不得在原版本上覆盖重算。
