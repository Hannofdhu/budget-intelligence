# 三类比例调平方案采用固定收入贡献目标

续班率与新生占比的三类候选调平方案采用固定、可解释的待调平收入贡献目标：平衡方案为 50%/50%，留存侧方案为 70%/30%，招生侧方案为 30%/70%。超目标降额时沿用相同的贡献比例。

如果某一侧受确认上限或下限限制，无法完成目标贡献，未完成金额转移给另一侧；候选方案必须同时展示默认目标贡献比例、边界内实际贡献金额、转移金额、转移原因和最终实际贡献比例。

系统暂不提供任意贡献比例滑块，避免候选方案组合数量和选择复杂度失控。数据维护人员如需其他压力结构，可以在候选方案应用到草稿后人工调整参数，但该草稿仍须经过完整校验和部门预算负责人正式确认。
