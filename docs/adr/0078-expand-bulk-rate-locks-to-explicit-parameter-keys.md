# 批量比例参数锁定展开为明确参数键清单

数据维护人员和部门预算负责人可以通过筛选器选中多个续班率或新生占比参数，批量执行锁定、解锁或修改并锁定。系统保存时必须将筛选结果展开为当时每个完整参数键的明确清单，不得保存动态通配规则；后续新增的校区、产品、年级、科目或其他维度值不会自动继承旧批量操作。

批量操作可以统一填写原因，但每条参数仍须分别保留修改前值、修改后值、锁定状态和完整参数键，并共同记录操作人、时间、参数版本及当时角色快照。

批量操作是原子操作。任一明细不满足确认上下限、0.01 个百分点精度、完整参数键或其他既定校验时，整批操作失败并展示逐条错误，不允许部分成功或静默跳过异常明细。
