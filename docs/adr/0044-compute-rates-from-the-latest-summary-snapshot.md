# 正式参数从指标宽表最新快照分区计算

续班率和新生占比的生产计算读取“智慧学习部指标汇总宽表”，行级口径追溯和明细核查使用“智慧学习部学员花名册”。由于指标汇总宽表是快照表，每次参数计算必须显式限定 `dtdate = MAX(dtdate)`，且只能读取该一个最新分区，禁止跨 `dtdate` 聚合或累加。

生成正式参数版本前，系统按同一数据截止边界，对账宽表最新分区与花名册中的正式分子、分母；任一字段不一致时阻止参数冻结，不自动选择其中一方。入口班历史占比仍直接从花名册计算，因为需要应用入口范围和人工纳入、排除规则。参数版本必须同时保存宽表最新 `dtdate`、宽表来源批次、花名册来源批次和对账结果。
