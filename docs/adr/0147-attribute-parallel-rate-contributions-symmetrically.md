# 并列比例杠杆采用双顺序平均归因收入贡献

续班率与新生占比同时调整时会产生交互收入，不能把两类参数的收入贡献简单定义为各自单独变化的差额，也不能固定先算其中一类。固定顺序会把交互项全部归给后计算的杠杆，使平衡、留存侧和招生侧方案的实际贡献份额依赖实现顺序。

系统以完成入口调整后的结果为共同基准，分别计算“只调整续班率”“只调整新生占比”和“两者同时调整”的完整整数人数及收入结果。续班率贡献取“续班率先加入”和“续班率后加入”两个边际贡献的平均值；新生占比贡献采用对称公式。两项贡献之和必须严格等于两类比例参数同时调整带来的收入变化。

该归因只用于候选方案的贡献软目标、解释和确定性择优，不改变目标收入、人数、班均、边界或发布硬约束。归因使用与正式预算相同的取整和收入计算内核，不使用线性近似或展示舍入值。
