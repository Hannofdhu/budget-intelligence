# 首个滚动预测继承年度预算基线的比例参数锁定

同一财年的首个滚动预测以已发布年度预算基线为父版本，继承续班率、新生占比的锁定值、锁定状态及审计来源。后续滚动草稿继续按照父滚动版本继承，数据或实际结果刷新不得自动解除锁定。

已达到成熟条件的季节改用冻结实际，继承的原锁定只保留在版本审计中，不再影响该季节计算。尚未成熟的未来季节继续执行继承锁定，已发生的实际偏差不得自动解除或修改未来季节锁定。

数据维护人员或部门预算负责人可以在滚动预测工作区显式锁定、解锁或修改并锁定未来季节参数，并形成新的滚动参数版本，使依赖旧状态的滚动候选方案和正式确认失效。
