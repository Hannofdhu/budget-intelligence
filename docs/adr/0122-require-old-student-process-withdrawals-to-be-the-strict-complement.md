# 老生同期过程退班分子必须是新生的严格补集

自然滚动预测正式使用“智慧学习部指标汇总宽表”的物理字段 `老生同期退班人次-过程值` 作为去年同期过程老生退班分子；该字段来源于“智慧学习部学员花名册”的 `老生退班人次-过程值`，不得由预算系统自行改写。

老生过程分类必须是新生过程分类在过程总退班人次中的严格补集：

`老生退班人次-过程值＝退班人次-过程值－新生退班人次-过程值`

对应到指标宽表：

`老生同期退班人次-过程值＝同期退班人次-过程值－新生同期退班人次-过程值`

系统必须在完整预算明细维度校验 `新生同期退班人次-过程值＋老生同期退班人次-过程值＝同期退班人次-过程值`，且三项均为非负数，不设置人数容差，也不得用上层汇总抵消明细差异。任一明细不成立时，老生退班指标保持“口径待核验”并阻断正式自然滚动预测。

预算系统不得在运行时用派生差值静默覆盖不合格物理字段。数据维护人员必须修正上游定义、刷新花名册和指标宽表，并在新的 `dtdate` 分区重新通过逐明细勾稽后，才能解除阻断。
