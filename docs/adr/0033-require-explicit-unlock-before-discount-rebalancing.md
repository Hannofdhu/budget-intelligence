# 折扣率调平必须在不可行缺口出现后显式解锁

入口分配、续班率和新生占比均达到已确认边界后仍存在不可行缺口时，系统先展示剩余缺口；只有业务方在当前预算草稿中显式选择启用折扣率调平，系统才能生成折扣率候选方案。折扣率继续作为最后一级次级杠杆，不得提前或静默参与调平。

明细折扣率可以在候选方案中重新分配，但结果必须满足已批准的部门、赛道、年度和季节综合折扣率约束。启用折扣率调平不代表允许修改这些上层综合折扣目标。如果在既定综合折扣目标内仍无法闭合，系统继续报告不可行缺口，不得自动突破。修改上层综合折扣目标必须建立新的参数版本，并由部门预算负责人单独审批。
