# 开放招生季度收入参数默认沿用父版本

开放招生季度按季末终值人次重算全季度收入时，除新生、老生终值人次外，产品价格、折扣率及其他收入参数默认沿用父滚动版本中的有效值。系统不得因为当季处于开放招生状态而自动用过程实际、峰值或其他临时口径覆盖父版本参数。

只有具备既定参数调整权限的角色执行人工调整并完成相应确认后，开放招生季度才使用调整后的收入参数。每次调整必须保留父版本值、调整后值、调整人、调整时间和原因，并触发季度收入、年度收入和预算缺口重新计算。

已定版季度只使用冻结实际，不适用父版本收入参数；未来未开始季度继续按既定父版本参数推演。
