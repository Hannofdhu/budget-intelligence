# 退班字段口径未配对时禁用自动终值预测

新生和老生的退班预测必须分别完成四项同口径字段配对：去年同期过程退班分子、去年同期过程退班分母、去年最终退班分子和去年最终退班分母。任意一项缺失、含义不明确或无法证明属于同一统计口径时，该组指标状态必须显示为“口径待核验”。

处于“口径待核验”状态的指标不得参与加法型剩余退班率、预计剩余退班人次或季度终值的自动计算，也不得用于发布正式自然滚动预测。系统不得使用当季新招新生字段、通用退班字段、目标字段、集团字段或其他近似字段静默替代。

新生和老生两组指标分别校验，但正式自然滚动预测要求两组均通过；未通过时可以保留滚动草稿并展示缺失字段和核验原因，等待数据维护或人工补充处理。

物理字段 `老生同期退班人次-过程值` 即使存在，也必须在完整预算明细维度满足 `同期退班人次-过程值＝新生同期退班人次-过程值＋老生同期退班人次-过程值`，且三项均为非负数。任一明细不成立时，老生指标继续保持“口径待核验”；系统不得在运行时以“总过程－新生过程”的派生值静默覆盖不合格物理字段。
