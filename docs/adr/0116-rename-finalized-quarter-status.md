# 财季最终状态统一表述为已定版

为降低业务理解成本，财季生命周期中的最终状态由“已财务关账”统一更名为“已定版”。“已定版”作为财季生命周期的最终用户可见状态名称。

“已定版”仍表示该财季已经满足正式实际冻结条件，使用版本绑定的冻结实际人次和收入，停止使用开放期预测参数并保持只读。此次调整只改变产品术语，不改变财务负责人确认关账、相关数据刷新、快照冻结、新版本修正和审计等既定业务规则。

产品页面、状态字段、校验提示、词汇表和后续文档统一使用“已定版”。描述实际财务动作或数据成熟条件时，仍可使用“财务关账”说明其事实依据，但不得再将“已财务关账”作为用户可选状态名称。
