# 滚动预测不得因营收缺口阻止发布

年度预算基线发布时，智慧伴学、智慧空间和部门合计必须分别进入正负一万元目标容差，该规则属于年度预算正式发布硬约束。自然滚动预测的目的则是客观揭示已冻结实际与剩余期间原有参数将形成的营收缺口，因此滚动预测无论缺口或超额金额多大，都不得仅因未达到年度预算目标而被禁止发布。

滚动预测的正式发布继续受数据完整性、实际映射、参数版本、角色确认和其他既定治理校验约束。营收缺口是必须展示和用于制定补缺方案的经营结果，不是滚动预测数据无效的依据。

季度、赛道和部门滚动差异的绝对值不超过一万元时，页面显示“无显著缺口”，并同时展示实际差异方向和金额。该一万元只作为滚动页面展示阈值，不构成滚动发布硬约束。
