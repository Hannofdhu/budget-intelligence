# 采用加法型剩余退班率预测季度终值

自然滚动预测对尚未结束且已经接近招生峰值的季度，不再只沿用父版本原有参数。系统分别对新生和老生，使用去年同季度从相同预测进度到季度最终的退班发展规律，估算今年预计还会发生的退班人次，并据此预测季度终值。

默认采用加法型剩余退班率，不采用退班率倍数放大：

`去年同期过程退班率＝SUM(去年同期过程退班人次)÷SUM(去年同期过程退班基数)`

`去年最终退班率＝SUM(去年最终退班人次)÷SUM(去年最终退班基数)`

`历史剩余退班率＝MAX(0，去年最终退班率－去年同期过程退班率)`

`今年预计剩余退班人次＝今年当前适用退班基数×历史剩余退班率`

`今年预计最终退班人次＝今年当前已退班人次＋今年预计剩余退班人次`

`季度终值人次＝当前在读人次＋预计后续新增人次－预计剩余退班人次`

所有退班率必须先按适用维度汇总分子和分母，再计算比例，不得平均明细行比率。新生和老生必须分别预测；预计剩余退班人次不得超过当前仍在读人数。去年同期过程数据缺失、分母为零或字段口径无法匹配时，进入既定回退流程或人工确认，不得将缺失值视为零。

该方法只用于形成客观的自然滚动预测，不得为了缩小预算缺口而反向调整历史剩余退班率。正式启用前，必须确认新生和老生各自的过程退班分子、最终退班分子及匹配分母来自同一统计口径；字段映射未核验通过时不得发布自动预测结果。
