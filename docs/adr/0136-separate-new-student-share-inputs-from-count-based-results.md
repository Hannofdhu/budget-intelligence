# 区分反推型新生占比与定量新生人次结果

只有在已推演老生理论人次大于零时，才允许把新生占比作为人数输入反推新生理论人次。反推公式为 `新生理论人次 = 老生理论人次 × 新生占比 ÷（1－新生占比）`；此类新生占比必须满足 `0% ≤ 新生占比 ≤ 99.99%`，不得输入或自动调平到 100%。

老生理论人次为零时，仅凭新生占比无法确定新生绝对人次，必须由业务方人工填写计划新生人次；系统不得填零、套用班均或使用隐藏比例。入口分配或人工计划已经明确新生绝对人次的预算行，以该人数作为输入，新生占比只按 `新生人次 ÷ 总人次` 计算结果，不参与该行人数反推或新生占比自动调平。

定量新生人次大于零且老生为零时，计算结果可以是 100%；新生和老生均为零时总人次分母为零，新生占比结果为不适用。系统必须标记该行的人数来源是入口分配、人工计划还是新生占比反推，不能把计算结果重新当作输入参数。
