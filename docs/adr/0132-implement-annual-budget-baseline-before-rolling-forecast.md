# 先实施年度预算基线，再实施滚动预测和补缺方案

预算智解按照以下依赖顺序分三期实施：

1. 年度预算基线：学校版目标导入、预算组合、入口分配、续班率和新生占比、人次推演、班均校验、价格与折扣、收入计算、调平、确认和发布；
2. 自然滚动预测：财季状态、定版实际、预计后续新增、退班预测、季度终值、预计收入和预算缺口；
3. 滚动补缺方案：基于已生成自然滚动预测的人工试算、参数调整、补缺结果确认和发布。

第一期发布的年度预算基线是第二期滚动预测的强制父版本；没有已发布年度预算基线时，不得创建正式滚动预测。第三期必须绑定第二期的具体自然滚动预测版本，不得直接从年度预算基线生成，也不得覆盖自然滚动预测。

当前上游老生同期过程退班字段仍存在数据质量阻断，不影响第一期年度预算基线实施，但在第二期正式启用退班预测前必须完成修复、刷新和重新核验。

第一期先形成可开发、可验收的本地 PRD、页面流程、字段清单和验收用例；后两期规则继续保留在既有 ADR 和术语表中，不提前混入第一期页面或发布流程。
