# 开放招生季度按季末终值人次重算全季度收入

自然滚动预测对处于“开放招生”状态的季度，采用预算化终值预测。系统不沿预测基准日拆分已发生收入和未来预计收入，而是分别使用 ADR-0120 定义的退班分类新生季度终值人次和退班分类老生季度终值人次，按照对应预算明细的完整季度收入参数重算整个季度收入：

`季度预测收入＝退班分类新生季度终值人次×新生完整季度收入参数＋退班分类老生季度终值人次×老生完整季度收入参数`

这里的“新生”和“老生”是与退班分子、分母一致的预测分类，不是宽表 `新生人次` 所代表的业务新生分类；业务新生人次只用于计算预计后续新增新生人次。

完整季度收入参数继续使用当前滚动版本中对应 `财季＋赛道＋产品＋年级＋科目＋校区` 明细的有效产品价格、折扣率及其他既定预算参数。预计后续新增新生人次、预计剩余退班人次或相关参数发生变化时，系统必须重算该开放季度的全部预测收入。

该方法不区分学员在季度内的具体加入或退班时间，也不单独保留开放季度预测基准日前已经产生的收入，属于预算口径的季末终值重算，不得表述为财务收入进度预测。

已定版季度不适用本规则，必须继续使用冻结实际收入，不得被季末终值人次或后续参数重算覆盖。尚未开始的未来季度继续按既定父版本参数推演。
