# 季度终值以预测基准日当前在读人次为起点

尚未结束季度的人次终值预测必须以预测基准日的当前在读人次为起点，分别计算当季新招新生和老生：

`新生季度终值人次＝当前在读新生人次＋预计后续新增新生人次－预计剩余新生退班人次`

`老生季度终值人次＝当前在读老生人次－预计剩余老生退班人次`

`季度终值总人次＝新生季度终值人次＋老生季度终值人次`

累计业务新生人次只用于计算校区业务新生人次预算缺口和预计后续新增新生人次，不得作为当前在读新生人次替代值。退班率分母只用于计算退班率及退班预测，也不得直接作为季度终值起点。

系统必须记录当前在读新生、当前在读老生的字段映射、数据集、`dtdate` 和来源批次。任一终值小于零或起点字段口径未核验时，系统必须报告口径或参数异常并阻断正式自然滚动预测。
