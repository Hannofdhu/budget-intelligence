# 招生状态可重新开放但已定版状态不可回退

财季处于“招生结束待定版”后，如果业务重新开放招生，数据维护人员可以将其重新指定为“开放招生”。该状态变化必须记录原因和来源批次，并生成新的滚动预测版本；原待定版版本保持不变。

重新进入“开放招生”后，系统必须按校区业务新生人次预算缺口重新生成预计后续新增默认值，继续计算预计剩余退班和季度终值，并撤销沿用自上一状态的相关参数确认。部门预算负责人完成新的最终确认后，版本才能发布。

“已定版”属于不可回退状态，不得重新改为“开放招生”“招生结束待定版”或“未来未开始”。已定版实际需要修正时，只能由数据维护人员修正来源数据或字段映射，并使用新快照生成新的已定版滚动版本；原已定版版本永久保留。
