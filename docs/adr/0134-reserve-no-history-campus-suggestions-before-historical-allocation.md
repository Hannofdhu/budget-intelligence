# 先预留无历史校区建议值，再按历史占比分配剩余入口

整套校区入口建议值必须严格汇总到财年入口总值。新校区、无可用历史校区先由业务方人工设置建议值并记录原因，形成无历史校区建议预留；预留合计不得超过财年入口总值。

有历史校区的建议理论值按 `（财年入口总值－无历史校区建议预留合计）× 该校区上一财年入口班业务新生人次 ÷ 全部有历史校区上一财年入口班业务新生人次` 计算。分子、分母继续使用上一财年确认的入口范围规则先汇总再相除；教室资源和销售资源不进入系统隐含权重，只作为业务确定值调整依据及资源硬边界。

无历史校区预留合计等于财年入口总值时，有历史校区建议理论值均为零；全体校区均无历史时，全部建议值由业务方人工设置，且整套建议仍须汇总到财年入口总值。建议值不直接生效，最终仍由部门预算负责人确认整套校区入口确定值。

本决策完整替代 ADR-0133。建议理论值转换为整数建议值的尾差规则仍另行确认。
