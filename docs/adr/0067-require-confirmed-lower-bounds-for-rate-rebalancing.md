# 续班率与新生占比降额调平必须有确认下限

为了在预算收入超目标时安全地向下调平，续班率和新生占比除确认上限外，还必须配置业务确认下限。默认建议下限取该参数的正式历史参考值，系统不得自动将经营目标降低到历史参考水平以下。

业务确需将下限设为低于历史参考值时，由数据维护人员填写业务原因，部门预算负责人通过独立动作确认并形成参数版本。下限未确认时，该参数不得参与自动降额调平；自动降额只能在确认下限以上进行。

每个参数必须满足 `0% ≤ 确认下限 ≤ 当前确认值 ≤ 确认上限 ≤ 100%`。确认下限或上限发生变化时都必须形成新的参数版本，并使依赖旧边界生成的候选方案、正式方案确认和折扣率调平解锁状态失效；原版本继续保留用于审计和比较。
