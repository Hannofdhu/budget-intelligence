# 数据维护人员和部门预算负责人均可锁定比例参数

数据维护人员和部门预算负责人都可以按完整参数键直接锁定或解锁续班率、新生占比，不要求另一角色再次确认。锁定操作必须明确指定参数类型、完整参数键、锁定值和原因，并记录操作人、操作时间、预算或参数版本及当时角色快照。

被锁定参数继续以锁定值参与人数推演和收入计算，但等百分点水位法必须跳过该参数。锁定、解锁或修改锁定值都必须形成新的参数版本，并使依赖旧状态生成的候选方案、正式方案确认和折扣率调平解锁失效。

锁定参数过多导致赛道或部门目标无法在其他既定边界内闭合时，系统报告不可行并展示锁定造成的受限金额，不得自动忽略、解锁或修改任何锁定值。
