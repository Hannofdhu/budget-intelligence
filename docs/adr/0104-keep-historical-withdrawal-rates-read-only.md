# 历史退班率只读且人工仅调整预计退班人次

自然滚动预测中的去年同期过程退班率、去年最终退班率以及由两者计算得到的历史剩余退班率属于只读历史证据。数据维护人员和部门预算负责人均不得直接修改这些指标，也不得通过人工调整覆盖其分子、分母或计算结果。

人工干预只能修改“预计剩余退班人次”。系统必须继续展示原始历史退班指标、系统预测退班人次和人工调整后退班人次，使业务判断与历史证据清晰分离。

历史源数据或字段口径确需修正时，必须由数据维护人员通过新的数据快照和退班口径核验记录处理，并生成新的滚动预测版本；不得在原版本内将数据修正伪装为人工预测调整。
