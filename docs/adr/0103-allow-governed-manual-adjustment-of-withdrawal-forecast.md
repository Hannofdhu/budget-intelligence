# 允许两类角色调整退班预测并由预算负责人确认

数据维护人员和部门预算负责人都可以人工调整自然滚动预测中的预计剩余退班人次。调整后必须重新计算新生、老生及其合计季度终值和预计收入。

系统必须同时保留基于加法型剩余退班率生成的系统预测值、调整前值、调整后值、调整人、调整时间和调整原因。人工调整不得覆盖或改写用于形成系统预测值的历史同期过程值、历史最终值、字段映射和数据快照。

调整后的预计剩余退班人次必须为非负整数，不得超过对应明细当前可退班人数，并继续满足校区、新老生类型与明细合计一致等既定校验。调整行为不等于最终确认；只有部门预算负责人能够最终确认退班预测，未经确认的结果只能保存在滚动草稿中，不得用于发布正式自然滚动预测。
