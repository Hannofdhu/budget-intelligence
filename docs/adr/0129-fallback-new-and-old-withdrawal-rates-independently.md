# 新生和老生退班率分别独立回退

同一预算明细中的退班分类新生与退班分类老生，分别从精确维度开始，按照 ADR-0123 独立寻找最近的可用回退层级。允许新生和老生采用不同层级，例如新生使用精确维度、老生使用去校区层级。

同层约束只在单个退班分类内部生效：同一分类的去年同期过程退班率与去年最终退班率必须来自同一回退层级。系统不得为了让新生、老生层级一致，而迫使历史条件更好的分类继续回退，也不得用一个分类的可用性替代另一个分类的样本校验。

系统必须分别记录和展示新生、老生采用的回退层级、样本分母、历史率及预计剩余退班人次。任一分类进入“无可用退班历史”时，只对该分类执行 ADR-0125 的人工填写流程，另一分类仍保留其自动计算结果。
