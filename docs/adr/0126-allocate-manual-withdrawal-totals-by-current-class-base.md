# 无历史退班合计按当前分类在班基数自动分摊

在“无可用退班历史”状态下，数据维护人员或部门预算负责人按 `财季＋校区＋退班分类` 填写预计剩余退班合计后，系统按照该范围内各 `赛道＋产品＋年级＋科目` 明细当前对应的退班分类在班基数占比分摊。

新生使用 `新生退班基数(在班基数)`，老生使用 `老生退班基数(在班基数)`。对应基数为零的明细不参与分配；不得改用业务新生人次、招生人次或平均分配作为替代权重。

系统先计算各明细的理论分配值，再使用既定最大余数法生成整数人次，保证明细合计严格等于人工填写的 `财季＋校区＋退班分类` 合计。分配结果不得超过各明细对应的可退班人数；人工合计超过该范围可退班人数总和时必须拒绝保存，不能通过跨校区、跨退班分类或负数明细抵消。

若该范围所有对应退班分类在班基数均为零，则允许填写的预计剩余退班合计只能为零；正数合计视为不可行并阻止保存。
