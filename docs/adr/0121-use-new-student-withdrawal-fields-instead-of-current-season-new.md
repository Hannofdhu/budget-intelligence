# 退班预测统一使用新生字段

自然滚动预测的新生退班分类统一由“当季新招新生”调整为“新生”。“智慧学习部指标汇总宽表”已经提供完整的新生同期过程分子、过程分母、最终分子和最终分母；因此不新增“当季新招新生同期退班人次-过程值”，也不得继续把当季新招新生字段混入新生终值预测。

新生历史剩余退班率按以下字段计算：

`去年同期过程新生退班率＝SUM(新生同期退班人次-过程值)÷SUM(新生同期退班基数(退班率分母)-过程值)`

`去年最终新生退班率＝SUM(新生同期退班人次)÷SUM(新生同期退班基数(退班率分母))`

`新生历史剩余退班率＝MAX(0，去年最终新生退班率－去年同期过程新生退班率)`

`预计剩余新生退班人次＝新生退班基数(在班基数)×新生历史剩余退班率`

所有比例必须先在适用维度汇总分子、分母再相除。字段缺失或分母为零时仍进入既定回退流程；“当季新招新生”相关字段可以继续用于其他经营分析，但不参与自然滚动预测的新生退班计算。
