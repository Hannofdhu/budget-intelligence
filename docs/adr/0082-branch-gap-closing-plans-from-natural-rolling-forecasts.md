# 补缺方案从自然滚动预测独立派生

数据维护人员和部门预算负责人都可以从已经生成的自然滚动预测发起补缺方案。每个补缺方案必须绑定具体自然滚动预测版本及其数据快照，并作为独立滚动草稿保存；自然滚动预测永久保留，不得被补缺方案覆盖或追溯改写。

补缺方案只能调整未成熟期间的入口分配、续班率、新生占比及其他获准杠杆，不得修改冻结实际。方案必须展示原自然预测缺口、每项参数调整、预计补缺金额、调整后季度及全年收入和剩余缺口。

数据维护人员和部门预算负责人均可发起、编辑和试算补缺草稿，但只有部门预算负责人可以执行正式方案确认并发布正式滚动补缺版本。同一用户可以兼任两个角色，不要求换人复核，但发起、编辑、确认和发布动作必须分别保留审计记录。
