# 财季实际按公共维度一对一匹配并继承入口属性

当前学校版预算“滚动表”共有 238 条有效预算明细；忽略“是否入口”后，按赛道、产品、年级、科目和校区仍为 238 个唯一组合，没有重复，也不存在同一组合同时具有入口与非入口属性的情况。

因此，财季实际按“财季、赛道、产品、年级、科目、校区”与预算行一对一匹配，匹配成功后直接继承该预算行的“是否入口”属性，不进行入口与非入口收入分摊。预算版本创建和发布时必须校验该公共维度键唯一；未来如果出现仅入口属性不同的重复组合，系统阻止发布。找不到对应预算组合的实际收入进入未映射实际清单，不得强行归入相近组合。
