# 比例参数锁定默认只在同一财年版本间继承

同一财年从已有预算或预测版本派生新草稿时，续班率和新生占比的锁定值、锁定状态及原始审计来源默认随父版本继承。数据刷新不得自动解除、改写或重新解释锁定状态；后续显式锁定、解锁或修改继续形成新的参数版本。

新财年默认不继承上一财年的比例参数锁定，避免旧业务判断在历史参考值、参数键或经营环境变化后继续生效。数据维护人员或部门预算负责人可以显式发起跨财年复制，但复制结果必须重新校验完整参数键、确认上下限和 0.01 个百分点精度。

无法在新财年精确匹配的参数键进入异常清单，不得静默丢弃、自动新增或通过去维度、相近名称等方式模糊匹配。存在未处理异常时，复制结果只能作为草稿保存。
