# 默认按校区新生人次预算缺口预测后续新增

自然滚动预测对尚未结束的季度，默认假设每个校区在新生人次总量上完成该财季预算值。系统按财季和校区计算：

`校区预计后续新增新生人次＝MAX(0，该财季该校区新生人次预算值－该财季该校区当前累计业务新生人次)`

当前累计业务新生人次已经达到或超过校区新生人次预算值时，系统默认预计后续新增新生人次为零，不生成负数。新生预计剩余退班继续按独立的退班预测规则计算，不得提前从预计后续新增新生人次中扣除。

系统将校区预计后续新增新生人次自动分摊到该校区的 `赛道＋产品＋年级＋科目` 明细。新产品和特殊招生项目可以先人工指定；剩余人数默认按该校区今年截至预测基准日的累计业务新生人次明细占比分摊。分摊必须采用可审计的整数取整规则，保证明细合计严格等于校区预计后续新增新生人次。分摊基数为零或不存在可用明细时，必须转为人工处理，不得静默分配。

该系统结果是自然滚动预测的默认值，但允许授权用户人工调整校区预计值或明细分布。每次调整必须保留系统默认值、调整后值、调整人、调整时间和调整原因；校区预计值发生变化后必须重新校验明细合计。无论采用默认值还是调整值，均须由部门预算负责人最终确认后才能用于正式自然滚动预测。

本规则代表明确的业务预测假设，不代表系统根据历史招生节奏独立判断校区必然完成预算。它替代 ADR-0092 中默认按去年同进度至季度最终的新增发展量估算后续新增人次的规则。
