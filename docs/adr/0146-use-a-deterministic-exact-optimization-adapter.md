# 调平采用确定性精确求解适配器并区分不可行与未完成

调平引擎采用可替换的精确整数优化适配器，一期参考实现使用 OR-Tools CP-SAT；业务计算内核负责对候选进行完整精度复算，只有求解器在完整硬约束模型上返回 `INFEASIBLE`，系统才能发布“不可行”结论。超时、资源不足、模型异常或求解状态 `UNKNOWN` 统一标记为“计算未完成”，不得伪装成业务不可行，也不得扩大容差。

求解按入口、比例、折扣三个阶段逐级开放变量，并使用固定随机种子、单一确定性搜索配置和既定字典序目标。应用任何候选前必须由纯计算内核复算并逐项通过发布约束；求解器输出本身不直接写入正式预算。
