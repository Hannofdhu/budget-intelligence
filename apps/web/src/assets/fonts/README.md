# Product font assets

Self-hosted, normal-style Latin subsets for the roles in `DESIGN.md` v1.2.
Poppins: 400, 500, 600, 700. Lora: variable 400–700. Chinese glyphs use the
documented system fallbacks; terminal/code fonts are unchanged.

Downloaded 2026-10-23 from the Google Fonts stylesheet for
`family=Lora:wght@400..700&family=Poppins:wght@400;500;600;700&display=swap`,
using its Latin-subset `fonts.gstatic.com` resources (Poppins v24, Lora v37).
No runtime request is made to Google Fonts. The WOFF2 files retain their
original bytes; the accompanying upstream OFL and copyright notices apply.

- [Poppins source](https://github.com/google/fonts/tree/main/ofl/poppins)
- [Lora source](https://github.com/google/fonts/tree/main/ofl/lora)
- [Poppins license](./Poppins-LICENSE.txt)
- [Lora license](./Lora-LICENSE.txt)

Typography is deliberately applied by role: Poppins for headings and dense
functional UI; Lora for narrative explanations. Numerical data keeps tabular
figures and the original formatting and precision.
