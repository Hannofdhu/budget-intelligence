# 小予 · 产品吉祥物

来源：预算智解原创建模设计，延续用户选定的「解构之窗」Logo。
Figma：[小予设计页](https://www.figma.com/design/urVasakXpz8irlxdEVlAUE?node-id=10-2)。

透明背景 SVG，统一 `viewBox="0 0 360 340"`，按原比例缩放。

| 文件 | 用途 |
| --- | --- |
| xiaoyu-hello.svg | 新对话迎接 |
| xiaoyu-think.svg | 分析等待 |
| xiaoyu-focus.svg | 排队、读取、首次引导 |
| xiaoyu-done.svg | 已完成操作的反馈 |
| xiaoyu-notice.svg | 连接失败、操作未完成、正在停止 |
| xiaoyu-rest.svg | 备用品牌素材，当前产品未使用 |

通过 `Xiaoyu.tsx` 使用，具体触发和尺寸以项目 `DESIGN.md` 第4.2.2节为准。
